# Current distribution and legacy source

Current proprietary CLI release: **0.8.1**, distributed through the [CLI website](https://kodermodule.com/en/cli-download.html). The final website delivery record confirms the 0.8.1 stable feed, 403 public checks, full size/SHA-256 verification of all 32 originals and both generations of default update checks. Update checks did not install the software.

This repository carries documentation and historical source; current kernel development source remains private. Koder develops its task kernel, native orchestration, permission boundary and delivery logic. The distribution also uses attributed third-party tools and resources under their own licenses. See [architecture and component provenance](docs/ARCHITECTURE-AND-PROVENANCE.en.md) and [third-party notices](THIRD_PARTY_NOTICES.md). This documentation update changes no license, visibility or runtime source.

Installation and downloads are managed on the [Koder CLI website](https://kodermodule.com/en/cli-download.html). Run `koder update` or enter `/update` in chat to use the managed updater and its official feed. GitHub hosts feature documentation, tutorials, release notes and history; no new binary GitHub Release is part of 0.8.1.

[Agent verification and delivery records](docs/AGENT-VERIFICATION.zh.md) retain the original quality failures. The [0.8.1 notes](docs/RELEASE-0.8.1.md) distinguish current build/publication checks from inherited 0.7.2 model and browser evidence.
