# 本机密钥与返回 CLI（0.8.4）

[English](LOCAL-ACCESS-AND-RETURN.md) · [简体中文](LOCAL-ACCESS-AND-RETURN.zh.md)

本指南适用于 Koder CLI 0.8.4；账号网页部署和真人浏览器返回验收与 CLI 发布分别记录。已有网页登录、二维码、轮询、受保护凭据与设备撤销保持可用。

## 使用访问密钥

1. 新开终端，运行 `koder login --key`。也可在 `koder login` 的选择菜单选“输入密钥，进入本机模式”，或从 Setup → KARMEN 账号进入。
2. 在专用隐藏输入中输入团队私下给你的访问密钥并回车。屏幕不显示内容；不要把密钥写在命令参数、任务对话、脚本、反馈或日志中。空回车或 Ctrl+C 取消。
3. 正确时显示“本机模式已开启 · 云端账号未登录”。运行 `koder setup` 配置你自己的模型，再运行 `koder` 开始任务。原有文件、工具、电脑权限和费用预算仍生效。
4. `koder account status --json` 返回 `state: local-access`、`user: null`、`cloudAuthenticated: false`。这表示本机使用入口已开启，不表示 KARMEN 网页账号已登录，也不提供云端权益。
5. 本机标记按当前用户的数据目录保存；重开终端仍可用。`koder logout` 关闭本机入口并退出已有云端会话。其他窗口已开始的任务在下一模型步骤检查代次，不会跨身份继续。

密钥不存入本机标记，也不发送给账号服务器或模型。标记不是云端令牌。只有在交互终端明确开启后，无头任务才可沿用本机模式；`--yes`、管道输入和 JSON 模式不会代替隐藏输入。已有云端服务仍要求真正的网页授权；运行 `koder login --open` 完成后会切换回已验证账号。

## 网页确认后返回 CLI

`koder login --open` 会先准备网页授权，再尝试登记当前用户的 `koder-login` 返回入口。只有系统登记成功且能识别原终端，链接才携带返回按钮提示。账号网页对应更新的部署和真人返回验收仍需单独确认；部署后，在设备授权已经确认且环境支持时显示“返回 Koder CLI”，点击只请求唤回原终端。

正式登录仍由既有 PKCE、服务端轮询、身份校验与受保护令牌保存完成。原终端始终按原流程继续，不因网页点击改变认证结果。点击按钮不会写入登录成功，也不能修复凭据存储错误。不要关闭正在等待的终端。浏览器可能询问是否允许打开本机应用；系统拒绝或没有切回时，手动切回原终端即可。手机扫码仍由原终端轮询完成，无须在手机打开桌面返回入口。

返回记录只包含本机终端目标与公开交易标识，最多保存十分钟；取消或授权失败会删除本次记录，过期不能唤起任务。不会开启 localhost 端口、运行网页传入的命令或建立第二个 Agent 会话。

| 环境 | 返回方式 |
| --- | --- |
| Windows | 当前用户协议项，唤回此前捕获并再次核对所属进程的控制台窗口。 |
| macOS | 私有的本机返回组件，唤回 Terminal/iTerm；不要求辅助功能或管理员权限。 |
| Linux X11 | 用户桌面协议入口，使用已有 `wmctrl` 和原窗口 ID。 |
| Wayland、SSH、嵌入式或不可识别终端 | 手动回到原终端；不因此中断账号轮询。 |

## 排查

- `LOGIN_KEY_INVALID`：访问密钥不正确，重试隐藏输入；不要发送密钥给支持人员。
- `LOGIN_KEY_INTERACTIVE_REQUIRED`：请在可交互终端运行 `koder login --key`。
- `LOGIN_LOCAL_ACCESS_INVALID`：本机标记损坏，运行 `koder logout` 后重新开启。
- `LOGIN_LOCAL_ACCESS_UNAVAILABLE`：本机目录写入失败，检查磁盘和当前用户权限。
- `LOGIN_RETURN_*`：返回窗口不可用不等于账号失败，以原终端的登录结果和 `koder account status` 为准。
- `LOGIN_STORAGE_UNAVAILABLE`：云端令牌未能安全保存，运行 `koder account doctor --json`。返回按钮不会掩盖此错误。

此前隔离验收记录覆盖本机任务、隐藏输入、取消、退出、代次变化、网页轮询和三平台协议适配测试；真人网页登录、真实浏览器外部应用提示及 Windows/Ubuntu 桌面点击仍为 **NOT_RUN**；隔离 macOS 组件编译不能代替真实桌面注册与聚焦。CLI 已发布不代替账号网页的发布证据与完整路径真人验收。

0.8.4 账号测试记录为 198 项通过、2 项本机密钥条件用例跳过，跳过项不能当成本轮已跑通本机密钥任务。真人注册及浏览器到桌面返回仍为 **NOT_RUN**。
