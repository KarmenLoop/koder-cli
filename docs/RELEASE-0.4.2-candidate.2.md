# Koder CLI 0.4.2-candidate.2 — unpublished

This increment retains candidate.1 and adds pinned media, browser and application Skill sources to the same discovery and execution path. It adds dependency discovery and verified project-local preparation, original timeline/CSV/article/render helpers, and a Jianying draft adapter that preserves existing drafts and rejects invented media metadata.

Nine third-party source bundles and one Koder-authored workflow are callable. Two upstreams remain reference-only because their redistribution terms do not cover this package. Original sources, attribution and adaptation records are retained. See the [English guide](VIDEO-BROWSER-SKILLS.en.md), [Chinese guide](VIDEO-BROWSER-SKILLS.zh.md) and [third-party inventory](../THIRD_PARTY_COMPONENTS.json).

Local functional acceptance covers a fresh browser session, a rendered video with audio, file exports, Jianying draft JSON and a Draw.io adapter. It does not certify every style, native Windows UI export, real accounts or real-model output quality. The four baseline failures recorded in [candidate.1](RELEASE-0.4.2-candidate.1.md) remain open. Production remains 0.4.1; this is not an available remote update.
