# Koder CLI 0.5.14

修复“轻量 CLI 不收集账号密码”导致登录步骤直接取消的问题。支持隐藏输入、当前任务短期私有句柄、邮箱/GitHub 绑定、已配置模型的 Key 更新，以及 Ubuntu 登录控件填充。每次使用都确认实际目标；填入不等于已登录。

Ubuntu 管理员密码由系统 sudo 提示接收，Koder 不保存密码。前台和 agentd 会话都支持取消、过期与单次使用；无头模式、缺驱动或结果未知时明确说明，不伪造成功。

[完整手把手教程](CREDENTIALS.zh.md)。保留原有全部功能和默认学习能力。官网未改；私有内核不放入公开源码树。发布附件中的验收收据区分源码、隔离 GUI 与真实账号，未测试的物理桌面和第三方登录不标为通过。
