# Koder CLI 0.5.17

修复旧会话反复提示“前次操作结果仍待核实”，连只读检查也无法继续的问题。

- 兼容旧版缺少状态字段的待执行记录，恢复后可只读诊断，未知写入或外部操作仍不自动重放。
- 新增 `/reconcile` 查看待核实编号；用户实际核对后可用 `/reconcile checked <调用编号>` 记录人工核对。记录重启后保留，原 UNKNOWN 回执不改为成功。随后另发新任务，原审批与电脑权限不变。
- 整行输入 `ESC`、`Escape` 作为取消控制；空闲时不会交给模型再启动一轮。
- 工具派发前及保存执行意图后再次检查取消。尚未发出的调用记为“未执行”，避免形成假的 UNKNOWN 锁；取消后的迟到模型回复不能继续发工具。
- 恢复期间暴露原生电脑维护工具的只读状态动作，排除扫描和修改动作。

升级后运行 `koder --version`，再打开原会话，按[会话恢复手把手教程](SESSION-RECOVERY.zh.md)操作。不要删除配置、会话或旧回执来解锁。

本版针对性回归 111 项通过，覆盖 928 条历史持久化、取消时序及 agentd 本地通信。完整的本次检查结果见发布附件 `ACCEPTANCE-RESULTS.json`。Windows 实机仍由 beta 专员验收；本版不新增真实邮箱、付费模型质量、Ubuntu 图形桌面或 macOS 签名锁屏通过声明。

Windows、macOS、Linux 包保留既有适用功能，只包含一套当前教程导出；旧发行包不覆盖，私有运行时源码不推送到公开仓库。
