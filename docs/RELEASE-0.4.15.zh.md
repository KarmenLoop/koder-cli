# Koder CLI 0.4.15

本版修复“工作还没完成，就达到 16/16 工具步骤上限”：默认不设任务轮次上限，保留取消、审批与可配置的费用预算。

## 任务执行

- 默认不限模型/工具轮次，旧 Profile 隐含上限不再截断任务。主动设置的 `koder harness steps N` 仍有效；`koder harness steps unlimited` 恢复不限次数。
- 费用预算按单个根任务计算。用 `koder harness budget` 填金额、币种和实际模型的输入/输出单价，主 Agent 与子 Agent 共用。每次模型请求前预留额度，返回后按用量核算；缺单价、缺用量或费用未核实会停止新请求。预算未设置时服务商正常计费。
- Esc、Ctrl+C、停止指令继续有效。取消只停止后续工作；结果不明的操作保留回执，不自动重放。
- Todo 支持依赖、增改、分页与重排，不再受原条数上限限制；独立 FIFO 排队继续保留。

## 子 Agent 与自寻技能

单个根任务最多保留 180 个尚未回收的子 Agent，实际并行程度仍受机器、模型服务和费用预算约束。子 Agent 使用已配置模型与原 Core、原审批；写入范围必须互斥。MCP、邮件、图形操作由主 Agent 负责，需要进一步拆分时交回主调度。不能把测试中的 180 个任务登记当作 180 个真实模型并发实测。

执行前的待确认操作和每步工具回执写入原会话，完整文本/回执可分页回读。`/subagents status` 查看，`/subagents cancel` 取消；收回名额不会把 UNKNOWN 自动变成成功。

缺技能时沿原 Skill 库执行“搜索 → 固定版本获取 → 阅读 → 再尝试”。联网与技能更新仍要相应授权，工具安装走原审批；同参数同错误反复失败会要求换候选或明确继续。Setup 可分别关闭自寻和子 Agent，`--yes` 不代开电脑权限。

完整命令、预算示例、两子任务练习和边界见[任务编排手把手教程](TASK-ORCHESTRATION.zh.md)。

## 1800 课课堂

中文课堂扩展为 120 单元、1800 课，原 180 课编号与内容保留。新增 1620 个案例课提供具体输入、操作步骤、验收结果、原理与变式练习；保留手把手/开发者路线、搜索分页、书签、笔记与本地进度。英文保留原 30 课。

[打开完整课堂](courses/index.zh.html)，或在终端运行 `koder learn 1800 --print --lang zh`。阅读、答题和实操完成分别记录，不把读完自动记作实操验收。

## 实际验证范围

综合 144 项无密钥回归与 6 项独立边界检查通过，覆盖原步数上限、预算、取消、持久回执、Todo、Skill、子任务与输入/常驻会话。课堂的 72 个内嵌 JavaScript 程序已在临时目录逐一运行并核对输出；未声称所有 1800 课的外部服务、设备实操都已执行。

真实模型质量评分与 180 个付费模型并发未测。Windows 10/11 无 Node 冷安装、PowerShell 5.1/ConPTY/IME、Windows-MCP 图形操作、真实邮箱/GitHub 写入及系统通知显示，对本次精确包仍为 NOT_RUN。未签名 macOS 锁屏组件继续单独保留候选。

Windows CMD、PowerShell 与 macOS 安装器使用同一版本运行包并校验 SHA-256。更新使用 `koder update`，随后 `koder --version` 应显示 0.4.15。需要回退时使用旧版固定安装入口，保留数据，并先核对尚未确认的副作用。

课堂合入后 26 项回归通过；72 个完整 JavaScript 基准程序及 1 个变式已实际运行。课堂含 189 道选择题、1611 道人工自查，原180课题目和进度兼容保留。内容抽查和浏览器检查有范围限制，不能据此声称1800项实操全部验收。

实际安装回归发现并修正了子代理模型匹配模块漏打包的问题；发版包将包含 CLI 动态加载所需的该模块。
