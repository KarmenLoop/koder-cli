# Koder CLI 0.5.12

修复提交任务后长时间等待、随后超时的问题：此前 15 秒响应头限制把服务端排队和推理时间当作连接等待，超时还会重复发出请求。现在默认等待响应头 180 秒，该类超时不再自动重发。总请求 10 分钟、响应空闲 90 秒、取消和任务记录机制保留。

交互任务在尚无可见回复时每 10 秒显示 `MODEL_WAIT`、耗时和当前阶段上限。可用 `KODER_API_HEADERS_TIMEOUT_MS` 设置响应头上限（最多 600000 毫秒）；旧的显式 `KODER_API_CONNECT_TIMEOUT_MS` 作为兼容项保留。连接检查命令本身仍采用较短的诊断超时。

Ubuntu/macOS 安装器显示已下载 MB、已知总量、百分比、耗时、平均速度和重试次数。没有总量时明确标注未知；校验、解压、激活分别显示状态。断点续传和 SHA-256 校验保留，不激活损坏或未下载完整的文件。

修复整盘授权误判：授权根目录 `/` 不再要求用户能直接写入根目录。实际文件操作仍逐项检查范围、符号链接和 Ubuntu 权限；用户可操作自己有权限的目录。运行 `koder permissions request --mode full` 并确认后开放完整能力范围，不等于获得 root 权限，也不自动安装系统依赖。

回归在 Ubuntu 24.04 x64/ARM64 虚拟机真实终端中提交任务，使用延迟 20 秒返回响应头的本地 API。实际结果和图形矩阵见发行附件 `ACCEPTANCE-RESULTS.json`；夹具不代表真实模型供应商、所有网络、物理 GNOME 或真实邮箱验收。

使用 `koder update` 或 [Ubuntu 专用安装入口](UBUNTU.zh.md)。所有原有平台功能、Skills、自主学习资源与课堂保留。官网不变。
