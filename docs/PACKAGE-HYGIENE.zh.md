# 安装包维护与本地遥测

本规则适用于后续 Koder CLI 迭代。新版本应更新既有能力入口，不把每次修订追加为一套独立插件、Skill 或运行时。功能、许可、可追溯来源与执行回执必须保留。

## 每项能力保留一个有效入口

- 修改同一个 Skill 时，沿用稳定 ID 和调用入口。新增版本不能与旧版本同时注册成重复能力。
- `vendor/skills/catalog.json` 的名称和别名必须全局唯一，查询前就检查，避免过滤查询掩盖冲突。
- 内置 Skill ID 和生态 Skill ID 分别检查重复。生态资源按 manifest 的文件清单和 SHA-256 入包；漏列、缺失、内容漂移会使构建失败。
- 上游项目中同名的说明文件不一定是重复注册。执行器、平台驱动、参考资源、上游原件和许可证不能仅凭同名或相同哈希删掉。
- 历史审计与旧源码继续保存在版本历史或开发证据目录，不能让运行时默认递归加载这些归档。

## 安装包只带当前教程

`scripts/package-plan.mjs` 生成逐文件清单，打包前固定路径、大小和 SHA-256，复制后再次核对。相同路径、大小写冲突、符号链接或复制期间变化会阻止交件。

当前内容包括：CLI 运行文件、内核依赖闭包、已登记 Skill、平台需要的驱动、完整课堂、当前版本的八份文字教程（中文/英文 × CMD/PowerShell/Linux/macOS）、许可与第三方来源说明。

不进入新安装包的内容：其他版本的文字教程、旧 `docs/courses/editions/` 重复导出目录、Finder/Git 元数据。只排除分发，不删除开发树或历史文件。教程生成器只向 `docs/tutorials/` 写一份当前版本导出；课堂索引与课堂内容仍照常生成。

通用包保留所有现有平台运行文件；macOS/Linux 包沿用既有平台选择，不带 Windows 专用二进制，Linux 不带 macOS 专用二进制。共享 Skill、教程与许可保留。没有原生 Linux 驱动的功能不会因此获得 Linux 实机验收。

每个包内都有 `PACKAGE-CONTENTS.json`，记录该包实际选择的 CLI 文件、平台、内置 Skill ID 与排除原因；内核文件另由 `kernel/MANIFEST.json` 记录。清单不列自身哈希，最终归档的 SHA-256 由发行 manifest 和 `SHA256SUMS` 保存。

```sh
npm run test:package-telemetry
node scripts/pack.mjs --out /绝对路径/本次构建/dist
```

输出目录必须不存在或为空。已有文件时返回 `PACKAGE_OUTPUT_NOT_EMPTY`，请换一个本次构建的空目录，勿覆盖旧证据。构建先在相邻临时目录完成全部归档和校验清单，再整体移入输出目录；失败不会把半套文件放到正式输出目录。临时目录只由本次构建负责清理。

发布前核对：包内路径/哈希与清单一致、当前教程八份齐全、登记能力没有缺失、实际调用回归通过。源码字节减少不能直接当作下载加速、内存下降或模型质量提升，压缩后大小与平台实跑分别记录。

## 小窗口按任务加载工具

安装资源齐全，不代表每次模型请求都应塞入全部说明与工具 schema。8K 模型的网站任务保留写文件、预览、设计流程和工具发现入口；暂未用到的 GitHub 研究和凭据输入 schema 按用户意图、引导补充或真实 `tool_inventory` 结果调入。调用过的工具在当前任务内保留。原参数、执行器、权限和审批不变，不增加工具次数上限，不为节省空间删除当前任务约束或未知执行回执。

回归需实际走 `tool_inventory → learning_read pack → learning_read open → 下一模型请求`，检查每个请求都保留当前项目约束且在模型窗口内。网站尚未生成时仍应交付未完成状态，不能把请求未超限当作网站已做好。

## 本地任务遥测默认开，可在 Setup 关闭

入口：`koder setup` → **本地任务遥测**。命令行也可操作：

```sh
koder setup telemetry status --json
koder setup telemetry off
koder setup telemetry on
```

设置为 `telemetry.enabled`，下一任务生效；未配置时默认开启。记录任务耗时、调用/失败/重试计数、服务商返回的 token 用量等本地统计，不记录任务原文、命令参数、邮件正文或凭据，不上传云端。缺失用量保持未知，不能用估算数字冒充服务商回执。

关闭后停止新任务统计器、统计日志和会话统计写入；既有日志保留。执行回执、取消、费用预算、必要故障诊断和独立配置的学习功能继续运行。这个开关不是“关闭所有日志”。内置执行器的逐题字段详见 [无头交付契约](HEADLESS-DELIVERY.zh.md)。

云端上传、强制联网和服务器反馈保持未启用。本地遥测开关不能视为用户同意上传数据。
