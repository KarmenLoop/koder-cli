# Koder CLI 0.7.1

[English](RELEASE-0.7.1.md) · [简体中文](RELEASE-0.7.1.zh.md)

修复首次网页登录被 15 秒进程启动检查提前中止的问题；登录界面出现后按授权事务自身的有效期等待，正常取消不再附带 `UPDATE_WORKER_FAILED`。终端焦点切换、方向键、鼠标和粘贴中的控制序列不再误触取消，真正的 Esc / Ctrl+C 仍可取消。

对话中输入“登录”“打开网站登录”或 `login` 会直接打开账号授权流程，不再把这条指令交给模型。`/login` 保留浏览器与二维码选择。工作中输入登录会先排队；登录界面独占输入期间不会把按键误当成后续任务，结束后恢复输入区。

浏览器已有有效 KARMEN 登录态时，可在官方设备授权页核对并确认，无须重复输入密码；账号锁定或主动重新验证仍按原规则处理。CLI 轮询领取并保存受保护会话后继续原入口，并在系统支持时请求聚焦原终端。Wayland、嵌入式终端或系统拒绝聚焦时，明确提示已登录、只需切回原窗口。没有新增 localhost 回调、令牌粘贴或浏览器 Cookie 读取。

登录失败会显示发生阶段、HTTP 状态、安全网络原因或网关 Ray 编号；自动打开浏览器失败时仍保留同一次授权链接并继续轮询。诊断不会保存授权链接、state、密码或令牌。登录与退出后会刷新对话身份和执行绑定。

本版同时保留未发布 0.6.4 候选中的 Skill/MCP 修复：REA 诊断与逆向路由、应用结果分页读取、内置 Python/Scrapling 网页采集、Skill/MCP 可用性检查。没有删减既有能力、教程或第三方许可；外部依赖与尚未接入的上游特性仍在兼容清单中逐项说明。

安装包及更新统一从 [CLI 官网](https://kodermodule.com/cli-download.html) 分发，保留已发布版本的原始资产。Windows/Ubuntu GUI、真人登录、真实邮件及通知仍由 beta 专员分别验收，不能用隔离测试代替实机结果。

查看 [完整登录教程](ACCOUNT-LOGIN.zh.md) 和随包提供的准确验收记录。
