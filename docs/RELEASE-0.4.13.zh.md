# Koder CLI 0.4.13

## 本版更新

- 输入区更紧凑：没有 Todo 时为两行，有清单时默认三行；多行草稿按内容增加高度。模型输出和工具执行时仍可输入。
- 会话 Todo 跟随原会话保存和恢复。Ctrl+T 或 `/todo toggle` 展开，最多六行；取消后执行中的事项回到待办，已完成项保留。清单打勾不能代替真实执行回执。
- 底栏一行显示当前模型、任务状态、排队数和快捷键。通过 `/setup → 会话界面` 配置，输入 `/reload-tui` 可重新加载，不重置对话。
- `/help` 支持翻页；空输入按 `/` 可选建议、模板和命令，Tab 只填草稿，编辑后再发送。继续使用原来的实时引导、FIFO 排队、取消与审批逻辑。

保留 180 课中文课堂、原 30 课英文教材、加密设备迁移、GitHub 绑定、邮箱、MCP、Skills、模型路由、多窗口隔离和权限边界。没有替换原执行器或另建记忆库。

## 安装与升级

使用[官网安装入口](https://karmenloop.com/download.html#cli)，或运行 `koder update`。确认 `koder --version` 显示 **0.4.13**。Windows CMD、PowerShell 与 macOS 使用各自安装脚本和同一版本化 CLI 运行包；桌面应用版本独立。

启动 `koder chat`，输入 `/help`，再试一个多步骤任务。执行中继续输入，默认 Enter 引导当前任务；Setup 可切换排队模式。接收回执表示下一安全步骤可使用补充，不代表已经改写正在传输的模型请求。Ctrl+J 换行要求终端区分它与 Enter；否则可粘贴多行文本。

## 验证范围与限制

会话界面候选的 146 项定向无密钥回归全部通过，无失败或跳过。真实 macOS PTY 使用脚本化模型，验证了空闲、Todo、引导、草稿保留、任务完成及帮助翻页等七个阶段。覆盖本地终端、鉴权回环 IPC、会话隔离、审批与邮箱输入回归；不代表模型质量评分或真实账号投递成功。发行包、安装与线上读回另行记录。

本版 Windows 10/11 冷安装、PowerShell 5.1、ConPTY/中文输入法和 Windows-MCP 图形操作仍待实机验证。macOS 全终端/输入法矩阵、真实模型质量、邮箱投递、跨设备迁移和账号重连仍保留各自未验状态。历史失败与 HOLD 记录不删除；独立的未签名 macOS 锁屏原型不包含在本包。

非 TTY 和 JSON 任务保持原行为，不绘制交互面板。审批期间由审批独占输入，排队文本、未发送草稿和 Todo 不能批准操作。没有上下文计量时明确显示未知。
