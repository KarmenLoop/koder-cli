# Koder CLI 0.6.3

本版修复已登录后发送第一句话却报 `MEMORY_BUSY` 的常驻会话问题：默认窗口遇到旧前台任务占用时会创建独立会话，升级后旧常驻进程仍在工作也可兼容。显式同名会话仍不能抢占原任务，历史、取消与费用预算保持。

聊天和 Setup 直接展示已登录身份。短期访问令牌过期但刷新授权仍有效时，显示自动续期，不误导为退出登录。“一键打开系统浏览器登录”仍打开官方授权页；已有网页登录状态可继续确认设备授权，受服务端锁定与重新验证策略约束。`koder account status --json` 保留脚本接口。

本包同时纳入此前已完成的斜杠命令教学、按主题选择课程、本机自检及脱敏诊断队列。生产日志/反馈服务尚未配置，返回 `DIAGNOSTICS_SERVICE_NOT_READY`，不宣称已上传云端；不会自动上传原始对话、密钥或项目文件。

运行 `koder update` 后新开 Koder 窗口。[CLI 官网](https://kodermodule.com/cli-download.html)提供 Windows、macOS、Ubuntu 包与教程；GitHub 仅同步说明文档。内核开发源码保持私有，第三方许可保留。

发行验收：发行回执分别记录源码回归 131/131、实际包回归 145/145，两组覆盖有重叠，不合计为新增测试数。隔离安装使用自有回环镜像、准确发行字节和既有兼容 Node；macOS ARM64 命令冒烟为 10/10。本次文档工作核对了回执摘要与包内文档字节，没有重跑产品测试。官网正式提升与当前稳定清单已确认；完整公网下载验收仍待发行负责人最终回执。真人扫码或浏览器登录、各平台原生凭据、Windows/Ubuntu 原生终端与 GUI、真实邮箱、通知可见性和模型质量重考继续单独记录。
