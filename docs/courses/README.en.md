# Koder CLI: 30 detailed lessons

All 30 lessons retain their original exercises and add hands-on and developer tracks. Learn by module: read the expected result, perform the step and keep evidence.

> Content baseline 0.4.11 · Expanded-course candidate. Existing koder learn remains available; --track is added in this candidate. If your public build lacks it, read this page or download the material. Reading never executes commands or connects accounts.

Suggested routes: beginners start with 1–7 and 16–18; daily use covers 8, 15 and 19–29; developers focus on 4–16, 18–22, 26 and 30. Estimated study times are not execution deadlines.

## How to study

1. Run `koder learn` in the shell or `/learn` in chat.
2. In this candidate, use `koder learn 21 --track hands-on`, `--track developer` for developer guidance, or `--track overview` for the original coach.
3. Export with `koder learn --print --track all --os powershell --lang en`. Use cmd/mac/linux for the other shells; do not mix their syntax.
4. Lesson IDs, exercises and progress remain unchanged. Extended assignments never run automatically; graduates can revisit a lesson by number.
