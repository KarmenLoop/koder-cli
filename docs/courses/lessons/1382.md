## 原理讲解

事实卡要区分观测单位、指标定义和适用范围。28人到场是人数，72本换出是书本数；72除以28可以得到均值，但不能证明每人相同。16除以20描述的是问卷回答者。由事实导出的计算可复算，由观察推到总体的判断需要额外假设，两者不应混写。

本案例的关键推理：只改表不改正文→按主张ID搜索全部引用
