## 学习目标

完成“建立目录单一来源”：由同数组生成导航与段落ID清单 将上述完整程序保存为自有目录的 case.mjs，运行 node case.mjs；先独立预测输出，再与固定输出对照。；解释基准与变式的结果。

## 原理讲解

信息架构把页面内容组织成读者可以回答的问题。活动页通常先解释是什么与适合谁，再提供时间地点和报名；顺序应根据真实任务调整。导航名称、页面标题与锚点需要一致，不让用户在同义空话中猜测。

本案例的关键推理：减少手动同步遗漏

操作方法：将素材拆成单问题卡片，做排序与命名，然后画内容树。为导航和目标段落建立同一份数据源，检查缺内容、长标题与重复ID。
