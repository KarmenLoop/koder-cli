# 140 · PPT叙事：每页只推进一个判断

单元 10 · 建议 30 分钟（含自行练习） · 0.4.16 配套教材

[课堂](../index.zh.html#lesson-140) · [总纲](../README.zh.md)

## 学习目标

完成「PPT叙事：每页只推进一个判断」的操作练习，能够解释结果、诊断常见问题并提交可核对的作业。

## 原理讲解

演示文稿不是把长文切成十页。每页应有明确结论、必要证据和与下一页的连接。先写听众要作出的决定，再规划页面顺序。内容密度取决于现场讲解还是独立阅读，两种用途不能用同一套字号和信息量硬套。

专题补充
演示的单位是听众完成的一个判断。结论标题告诉读者该页意义，图表和例子提供支撑，讲述承担必要推理。信息密度随现场讲述与独立阅读变化。页数和视觉效果都不能替代决策逻辑；没有明确比较口径，推荐页再漂亮也难以说服。

先写会议结束时要作的决定，再逐页写一句结论和一条支持证据。将页面连成问题、证据、选项、取舍与行动的推理链；试讲时按听众疑问调整顺序，而不是逐页增加文字。

先完成第139课。使用自有Koder Projects练习目录和合成数据；阅读示例不会执行命令。账号、图形操作和外部写入须另有可用环境与授权；没有条件就记录NOT_RUN。


标题表达结论，正文支持结论。

### 跟做 1：清点输入与交件

把本课材料逐个命名，标注数据口径、日期和单位。写清需要表格、周报、PPT 还是邮件草稿，哪些必须可编辑。

检查点：同一事项在不同软件里的表达有共同事实来源。

### 跟做 2：先做统一计算或事实表

去重与缺值处理先写规则，再进行汇总。把计算式和分母保留在表中；文稿与演示从同一份已核对结果取数。

检查点：人数、金额和比例可重新计算，不从截图凭感觉抄数。

### 跟做 3：转换为读者可用的形式

按本课任务制作正文或页面，每张演示只支持一个主要判断。邮件明确收件人、主题、正文和附件；课堂默认保存草稿。

检查点：内容和格式都可编辑，附件名与实际文件一致。

### 跟做 4：处理变更与交接

修改题目指定的数字、时长或对象，列出受影响产物并逐一更新。发送或发布是独立动作，没有实际回执就保持草稿或未验。

检查点：改变源数据后不会只更新一份报告而留下旧 PPT。

### 本课交件自评

每项 0–2 分：缺失或错误 / 有结果但缺依据 / 结果与依据齐全。

- 交件格式和读者明确
- 数字口径、单位与分母一致
- 正文和演示支持具体决定
- 变式传播到全部相关产物
- 草稿、提交与实际送达区分清楚

### 开发者复盘

从数据源到报告、演示和草稿建立依赖关系。金额用明确单位与舍入规则，测试取消、缺失和重复行。邮件发送沿原审批及凭据存储，课程不能自动获取真实收件箱。

工作簿结构检查只能提示哪些栏目未填；正确性仍须核对本课输入、结果、变式和参考答案。

## 手把手操作

1. 写下本课目标、当前工作区和预期产物。保留练习原件，在副本操作。

   应看到：目标聚焦「PPT叙事：每页只推进一个判断」，可与本课示例对照；无无关真实资料。

2. 确定听众与时长

   应看到：决定页数和深度。

3. 写每页一句结论

   应看到：形成故事线。

4. 放必要证据

   应看到：避免装饰性数字。

5. 检查前后连接

   应看到：读者能跟上推理。

6. 整理本次实际结果与仍未确认的内容，把证据链接到作业。

   应看到：记录与「标题表达结论，正文支持结论。」逐项对照，不把未执行项填成通过。

7. 写会议前未知与会议后要确定的一件事

   应看到：目标为选下周两场安排，材料围绕选择服务

   为什么：分享范围无限，决策目标才能筛材料

8. 改变条件：听众改为新志愿者培训

   应看到：目标改为掌握现场流程，原方案比较需缩短或移除

   为什么：六页应围绕排期决定推进，预算只覆盖所选方案而不假设无限人手。A成本400、B350；C缺明确导师时间，不能写成已排定。

## 故障恢复

- **结果与示例不一致**：不要为了凑页数重复同一个卖点。 先保存原始错误，再从第一次偏离预期的步骤定位。

- **当前环境不能完成真实操作**：完成资料阅读、合成演练和验收计划，标明缺少的账号、运行时或设备。不要伪造回执，也不要为了过课扩大授权。
