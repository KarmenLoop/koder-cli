## 学习目标

完成“比较录入方式的暴露面”：列history、进程参数、截图风险；解释基准与变式的结果。

## 原理讲解

API Key、客户端授权码与环境变量引用承担不同角色。秘密应通过受控输入或已配置环境传入，不进入命令历史、截图、模板和反馈包。知道凭据存在不等于具有所需范围；登录成功也不能自动批准所有后续外部动作。

本案例的关键推理：隐藏输入不保证后续输出不会泄露

操作方法：全部练习使用SYNTHETIC_SECRET等假值。先绘制秘密可能进入的路径，再设计只输出存在性与来源的诊断。比较掩码输入、环境引用与命令行明文，练习撤销后重新确认可用状态。
