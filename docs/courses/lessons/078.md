# 078 · 三种版式：用结构差异帮助选择

## 学习目标

完成「三种版式：用结构差异帮助选择」的操作练习，能够解释结果、诊断常见问题并提交可核对的作业。

## 原理讲解

三个方案应该有不同的信息组织，而不仅是换颜色。可比较“海报导向”“流程导向”“编辑式叙事”，分别适合快速吸引、解释过程和讲清故事。每个方案保留同一份事实内容，才不会把文案差异误当成布局优劣。

专题补充
三个设计方案要有不同的阅读路径，而不是只换配色。海报式强调立即识别活动，流程式帮助理解当天安排，编辑式帮助建立背景。比较时保持事实、主要动作和内容长度一致，才能看出布局本身的影响。

先画黑白低保真，再为每案写适合场景、主要风险与手机转换方式。用同一组任务比较，选定后只深化一个方案，并保留取舍记录。

## 准备

先完成第77课。使用自有Koder Projects练习目录和合成数据；阅读示例不会执行命令。需要运行脚本时先核对本机运行时；不为阅读课程自动安装任何软件。

## 示例与解读

```text
A：大标题+日期地点+报名
B：活动流程时间线+侧边报名
C：主办者故事+活动内容+报名

补充案例：画海报式首屏
内容=标题、日期、地点、50字介绍、报名入口
```

三案主要动作相同，但阅读路径不同。

### 跟做 1：确定访问者主路径

用本课素材写一句“谁进入页面，要完成什么”。列内容层级、主要按钮和需要保留的事实。若本课是设计比较，让方案使用同一份内容。

检查点：不同方案比较的是阅读顺序和交互结构，不只是颜色。

### 跟做 2：搭出最小可见结果

先创建一个可打开的页面或线框图。把标题、说明、输入、错误与结果状态放到明确位置，再实现本课要求的局部变化。

检查点：主动作能被看见；空态、失败或未知状态有位置。

### 跟做 3：按真实路径跟做

从首次打开开始，用鼠标和键盘各走一遍。表单题输入空值、错误值和合成正确值；布局题缩窄窗口、放大文字。

检查点：保留用户输入，焦点可见，结果文案与实际状态一致。

### 跟做 4：交付可复看的证据

保留页面文件、运行方法和检查记录。变式修改指定素材或状态后再看一遍；部署只在本课明确授权且具备环境时另做。

检查点：本地预览与正式 URL 分别记录，不凭页面外观宣称服务器已收到数据。

### 本课交件自评

每项 0–2 分：缺失或错误 / 有结果但缺依据 / 结果与依据齐全。

- 主用户路径清楚
- 结构与视觉层级服务内容
- 正常和异常状态可辨认
- 键盘与窄屏有实际检查或明确未验
- 交件可打开并说明预览范围

### 开发者复盘

优先使用语义元素、标签和可见焦点。表单状态区分 idle、submitting、confirmed、failed、unknown；服务端确认前不显示完成。对本课变式测试 DOM 状态和用户路径，而不只比截图像素。

工作簿结构检查只能提示哪些栏目未填；正确性仍须核对本课输入、结果、变式和参考答案。

## 手把手操作

1. 写下本课目标、当前工作区和预期产物。保留练习原件，在副本操作。

   应看到：目标聚焦「三种版式：用结构差异帮助选择」，可与本课示例对照；无无关真实资料。

2. 冻结同一份内容

   应看到：不为某方案增删重要事实。

3. 画三张低保真布局

   应看到：先看层级和位置。

4. 给每案写取舍

   应看到：说明适用访客。

5. 请用户选择并记录原因

   应看到：选中后再做细节。

6. 整理本次实际结果与仍未确认的内容，把证据链接到作业。

   应看到：记录与「三案主要动作相同，但阅读路径不同。」逐项对照，不把未执行项填成通过。

7. 用四块低保真布局突出活动条件

   应看到：首屏能识别活动与行动

   为什么：大标题不能吞掉日期地点

8. 改变条件：标题扩展到30个汉字

   应看到：检查换行后关键信息仍可见，调整层级而非删事实

   为什么：检查日期地点可见性、阅读顺序、表单入口和长内容表现。不能把某方案删掉费用后显得简洁，当成它信息层级更好的证据。

## 故障恢复

- **结果与示例不一致**：不要同时把三个完整站点都上线；选择阶段只需本地预览。 先保存原始错误，再从第一次偏离预期的步骤定位。

- **当前环境不能完成真实操作**：完成资料阅读、合成演练和验收计划，标明缺少的账号、运行时或设备。不要伪造回执，也不要为了过课扩大授权。

实现前固定输入、输出、错误与权限契约。为本课关键边界设计一个应通过与一个应拒绝的用例。
