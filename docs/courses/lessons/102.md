## 学习目标

完成「文件上传：限制路径、类型和大小」的操作练习，能够解释结果、诊断常见问题并提交可核对的作业。

## 原理讲解

上传是把不可信输入带入系统。文件名可能包含路径片段，扩展名不保证内容类型，大文件会耗尽资源。保存位置应由服务决定，用户原名只作展示。读取和下载同样需要授权，不能因为文件已在磁盘就公开。

专题补充
上传把不可信字节与名称带入系统。文件名可能包含路径，扩展名可能与内容不符，压缩内容还可能解开后远大于原文件。服务端决定存储位置与身份，原名只用于受控展示；下载也要核归属。

先定义字节上限、类型验证、存储命名、所有者和清理策略。按接收、验证、保存、发布四阶段推演，每步失败只清理自己创建的临时资源。

```text
上传契约：最大字节数、允许类型、目标目录、随机存储名、所有者、校验结果

补充案例：限制接收字节数
上限1024字节，分块600+500

可复制的离线 Node 样例（仅计算合成数据或内存时序）：
(async()=>{const limit=1024,chunks=[600,500];let received=0;let accepted=true;for(const size of chunks){received+=size;if(received>limit){accepted=false;break;}}return {received,accepted,published:false};})().then(value=>console.log(JSON.stringify(value)));
```

开发者加餐
