# 031 · 找到正确的终端与当前目录

单元 3 · 建议 30 分钟（含自行练习） · 0.4.16 配套教材

[课堂](../index.zh.html#lesson-31) · [总纲](../README.zh.md)

## 学习目标

完成「找到正确的终端与当前目录」的操作练习，能够解释结果、诊断常见问题并提交可核对的作业。

## 原理讲解

终端是输入命令的窗口，Shell才是解释命令的程序。Windows Terminal可以同时打开PowerShell和CMD，标签标题不能保证其中运行的解释器。当前目录决定相对路径落在哪里：相同的README.md在两个目录中是两个文件。先确认位置，再让Agent动手，能避免“改好了却找不到”的大多数困惑。

专题补充
终端窗口、Shell进程与当前目录是三个不同对象。相对路径由当前目录解释，父进程的目录通常只在启动子进程时传入；一个子进程改变目录不会让另一个窗口跟着移动。使用Node的process.cwd可以跨平台观察位置，但Shell内建命令仍各有语法。

在自有练习根建立a和b两个子目录，分别放内容为A与B的marker.txt。每次读取前先显示绝对位置，再读取marker。比较不同窗口、子进程和编辑器启动的结果，把位置显式加入任务说明。

## 准备

先完成第1、4、18课。使用自有Koder Projects练习目录和合成数据；阅读示例不会执行命令。需要运行脚本时先核对本机运行时；不为阅读课程自动安装任何软件。

## 示例与解读

```text
PowerShell: Get-Location
CMD: cd
macOS/Linux: pwd

补充案例：用标记文件证明当前目录
a/marker.txt=A；b/marker.txt=B
```

输出应是你准备练习的目录；它不必等于Koder安装目录。

### 跟做 1：建立最小目录

在自有练习目录创建 input、output、notes 三个子目录。将本课给定文本写到 input 中，先列目录并读回文件，确认没有在安装目录里编辑。

检查点：目录层级和文件内容与题目一致，路径包含空格时仍可定位。

### 跟做 2：拆开命令理解

将本课命令拆为程序、参数、输入、输出、重定向五部分。遇到管道，说明每段从哪里读取、向哪里写；先检查单段再组合。

检查点：能解释 stdout、stderr 和退出码分别代表什么。

### 跟做 3：运行并记录差异

只在副本执行本课任务。保存关键输出和退出码；对文件转换，逐行比较输入与输出，明确编码、换行和相对路径。

检查点：失败不会被空输出或最后一条 echo 掩盖。

### 跟做 4：搬迁后复做

复制练习到新的自有目录，优先用相对路径复做。Windows 的 PowerShell/CMD 与 macOS Shell 语法分别记录，不机械复制。

检查点：新目录仍能读到相同输入并得到相同业务结果。

### 本课交件自评

每项 0–2 分：缺失或错误 / 有结果但缺依据 / 结果与依据齐全。

- 目录和输入可重建
- 命令参数与重定向解释正确
- 输出、错误与退出码均有记录
- 空格、编码或缺文件边界有一项检查
- 换路径后不依赖作者机器的绝对位置

### 开发者复盘

将 cwd、环境变量与临时目录作为测试参数。先构造输入边界再断言退出码和文件内容。对本课涉及的流处理，验证 EOF、无输入和坏参数，不用无限等待掩盖阻塞。

工作簿结构检查只能提示哪些栏目未填；正确性仍须核对本课输入、结果、变式和参考答案。

## 手把手操作

1. 写下本课目标、当前工作区和预期产物。保留练习原件，在副本操作。

   应看到：目标聚焦「找到正确的终端与当前目录」，可与本课示例对照；无无关真实资料。

2. 打开终端并记下所用Shell

   应看到：写下PowerShell、CMD或zsh/bash；不要把提示符也复制进命令。

3. 查看当前位置

   应看到：得到一个绝对路径。

4. 进入自己的Koder Projects练习目录

   应看到：再次查位置，确认路径已改变。

5. 请求Koder只列出当前目录文件

   应看到：对照终端输出，确认双方指的是同一目录。

6. 整理本次实际结果与仍未确认的内容，把证据链接到作业。

   应看到：记录与「输出应是你准备练习的目录；它不必等于Koder安装目录。」逐项对照，不把未执行项填成通过。

7. 分别进入a、b，运行node -p "process.cwd()"并读marker

   应看到：两次绝对目录不同，内容依次A与B

   为什么：相对路径通过cwd解析

8. 改变条件：两份marker内容都改A

   应看到：内容不能再区分位置，必须保留绝对路径观察

   为什么：通过标准是能预测同一相对文件名在不同cwd读到什么，并从实际文件确认。不存在的目录需要明确失败，不能静默退到其他目录继续写。

## 故障恢复

- **结果与示例不一致**：路径有空格时整体加引号；显示找不到目录时先查拼写，不重复安装Koder。 先保存原始错误，再从第一次偏离预期的步骤定位。

- **当前环境不能完成真实操作**：完成资料阅读、合成演练和验收计划，标明缺少的账号、运行时或设备。不要伪造回执，也不要为了过课扩大授权。
