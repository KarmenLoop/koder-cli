## 学习目标

完成「不会就学：教程检索接上实际操作」的操作练习，能够解释结果、诊断常见问题并提交可核对的作业。

## 原理讲解

面对陌生应用，先查官方文档或帮助页，提炼少量可执行步骤，再回到已授权工具操作。学习不是只贴一堆链接给用户，也不是让网页指令覆盖原权限。流程不符时换来源或通道，有界恢复后如实报告卡点。

专题补充
教程提供的是关于流程的知识，实际操作需要当前工具、状态和授权。学习成果应是可执行短计划与理解到的规则，不是链接堆积。界面名称变化可能不改变业务意图，版本差异却可能改变字段或副作用；操作后要核产物而非只完成点击序列。

遇到陌生流程先写目标与成功标准，再找该应用的当前官方帮助。将相关段落提炼为少量操作假设，回到可用工具观察实际界面，逐步验证；不符时按版本与入口定位，而不是不断照抄教程。

## 准备

先完成第158课。使用自有Koder Projects练习目录和合成数据；阅读示例不会执行命令。账号、图形操作和外部写入须另有可用环境与授权；没有条件就记录NOT_RUN。

2. 在 workbook.md 的“操作前的预测”写出预期，然后完成：完成「不会就学：教程检索接上实际操作」的操作练习，能够解释结果、诊断常见问题并提交可核对的作业。。
3. 按下面的方法保存实际步骤与结果，先不复制参考答案。
4. 只改变这项条件：用一个陌生合成网页流程做学习记录：来源、步骤、结果、卡点。。保留基准，再独立完成变式。
5. 用自评表和课堂参考核对，说明证据缺口；有实际作品时保留可编辑文件。

### 跟做 1：画出能力链路

按本课情境列出 CLI、Skill、工具、MCP server 与真实目标。标明谁提供说明、谁执行、谁授权、谁保存回执。

检查点：能解释 Skill 被找到不等于工具已运行。

### 跟做 2：先查现有能力

检查本地目录和已连接工具，缺项再按既有权限查官方说明。记录来源、版本和适用平台，不直接执行教程里的任意脚本。

检查点：复用已有入口，网络、安装和桌面授权各自核对。

### 跟做 3：用最小目标验调用

先做一个有明确输入与输出的合成任务。MCP 分别检查握手、工具列表、调用和结果；子 Agent 分别检查任务归属、结果和取消。

检查点：工具声明、调用成功和真实外部效果不会混成一个状态。

### 跟做 4：变更后重验边界

按本课变式修改环境、权限或能力选择，检查拒绝与恢复路径。经验候选只记录实际证据，不把一次自评直接变成默认规则。

检查点：原 Core 的权限、预算与取消继续生效。

### 本课交件自评

每项 0–2 分：缺失或错误 / 有结果但缺依据 / 结果与依据齐全。

- 工具链各层职责清楚
- 来源与适用条件可核对
- 最小调用有输入输出证据
- 缺权、缺驱动或取消有正确处理
- 能力改进保留原执行与权限边界

### 开发者复盘

为协议输入、工具结果、断开、取消和重连分别写断言。子任务共享父预算和授权，结果必须保留完整回执或可读取引用。JIT/经验层只调整受控配置，不修改凭据、权限或成功判据。

工作簿结构检查只能提示哪些栏目未填；正确性仍须核对本课输入、结果、变式和参考答案。

## 手把手操作

1. 写下本课目标、当前工作区和预期产物。保留练习原件，在副本操作。

   应看到：目标聚焦「不会就学：教程检索接上实际操作」，可与本课示例对照；无无关真实资料。

2. 识别目标和成功标准

   应看到：不只说应用名字。

3. 查官方帮助

   应看到：确认版本与入口。

4. 提炼3–5步

   应看到：不复述整篇。

5. 实际执行并观察

   应看到：不符则有限修正。

6. 整理本次实际结果与仍未确认的内容，把证据链接到作业。

   应看到：记录与「来源URL与实际执行步骤分别记录。」逐项对照，不把未执行项填成通过。

7. 缩到导出活动人数CSV，列必须与不需要字段

   应看到：目标可验为活动和人数两列，不包含联系人

   为什么：清楚结果才能选择教程段落，泛学无法确定完成

8. 改变条件：用户改要可编辑图表

   应看到：先定义图表与数据要求，CSV导出只是可能前置

   为什么：合格计划应从当前数据菜单定位导出，并在确认前排除姓名电话。只读帮助不证明CSV已生成；导出文件需核字段、行数与统计口径。

## 故障恢复

- **结果与示例不一致**：网络权限缺失时不能偷偷联网；教程内容也不授予写入权限。 先保存原始错误，再从第一次偏离预期的步骤定位。

- **当前环境不能完成真实操作**：完成资料阅读、合成演练和验收计划，标明缺少的账号、运行时或设备。不要伪造回执，也不要为了过课扩大授权。
