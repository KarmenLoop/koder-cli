# 001 · 开场：欢迎来到 Koder 训练营

单元 1 · 建议 25 分钟（含自行练习） · 0.4.16 配套教材

## 学习目标

分清系统终端、Koder 对话与练习场；完成第一次离线练习，并知道作品放在哪里。

## 原理讲解

嗨，我是 Koder 教练。中文课堂共 1800 课，保留原 180 课并增加 1,620 个案例。前 30 课保留内置练习场，后续课程提供分单元讲解与自行实操；阅读不会自动连接账号或发布。
内置教练演示不用配置模型、不调用付费 API：替你干活的是我这个“教练模型”，台词提前写好了，演技有限，请多包涵。但改文件、跑命令都是真的，走的就是 Koder 平时用的那套内核。

专题补充
学习环境有三个独立对象：接收键盘的终端、解释命令的 Shell，以及 Koder 内创建的练习目录。会话进度是记录，源文件是作品；记录能恢复并不表示临时文件还在。课程阅读、脚本教练、自己的模型任务也有不同成本。先建立能够定位和搬走的学习成果，之后每次排错才有可靠起点。

用一张两列索引把“屏幕显示的名称”映射到“实际对象”。终端命令只在 Shell 输入；聊天中的斜杠操作只在 Koder 输入。对目录先取绝对位置，再看文件内容；对课程先标阅读或实操，再记录产物。示例中的路径是合成数据，动手时应替换成自己的练习目录。

## 准备

准备一个可复制粘贴的终端。先阅读安装说明；已经装好则不必重装。练习场是临时目录，毕业时选择保留才会留下文件。扩展作业使用自己的独立目录，不放在安装目录。

## 手把手操作

1. 在系统终端运行 koder --version，记下版本。再运行 koder help。

   应看到：能看到实际版本和命令列表；命令不存在时先按第16课排查安装入口。

2. 运行 koder learn；在第一课选择自己正在使用的 PowerShell、CMD、macOS 或 Linux。

   应看到：出现练习场路径。这里的教练不调用付费模型，但文件修改和测试确实发生在练习场。

3. 回车前进，输入 4 跳到差异课；练习拒绝一次、接受一次。输入 q 离开，再运行 koder learn。

   应看到：重新进入时能继续进度；退出默认清理练习文件，进度与文件不是同一回事。

4. 要做自己的项目，离开教程后运行 koder project create "Learning Site" --kind website，再看 koder project list --json。

   应看到：新项目有独立目录。按返回路径打开项目，不猜目录名，也不把教程临时路径当正式项目。

5. 画终端→Shell→koder learn→临时购物车四节点，把当前位置标在 Shell 上

   应看到：图中 /lab 和 /tmp/cart-7 是两个目录；模型调用节点为零

   为什么：窗口只是容器，工作位置会在程序间变化，路径能够解释作品落点

6. 改变条件：把终端改为 Windows Terminal、Shell 改为 PowerShell

   应看到：节点关系相同，查看位置命令换成 Get-Location，不改变课程目录含义

   为什么：核对材料必须同时覆盖入口、当前位置、文件内容与保留方式。截图能够说明当时看到什么，却不能代替文件；文件存在也不能证明它来自本轮。练习后关闭再打开记录文件，检查路径是否仍有效，并确认正文没有只有一段“已完成”。

## 故障恢复

- **q 退出后找不到购物车文件**：这是练习场清理，不是作品丢失；需要留存时到毕业课明确选择保留。

- **把 /setup 输入系统终端**：先运行 koder 进入对话，或直接用系统命令 koder setup。
