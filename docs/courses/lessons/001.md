## 学习目标

分清系统终端、Koder 对话与练习场；完成第一次离线练习，并知道作品放在哪里。

## 原理讲解

嗨，我是 Koder 教练。完整课堂共180课。前30课保留内置练习场，后150课是分单元讲解与自行实操；阅读不会自动连接账号或发布。
内置教练演示不用配置模型、不调用付费 API：替你干活的是我这个“教练模型”，台词提前写好了，演技有限，请多包涵。但改文件、跑命令都是真的，走的就是 Koder 平时用的那套内核。

## 准备

准备一个可复制粘贴的终端。先阅读安装说明；已经装好则不必重装。练习场是临时目录，毕业时选择保留才会留下文件。扩展作业使用自己的独立目录，不放在安装目录。

## 手把手操作

1. 在系统终端运行 koder --version，记下版本。再运行 koder help。

   应看到：能看到实际版本和命令列表；命令不存在时先按第16课排查安装入口。

2. 运行 koder learn；在第一课选择自己正在使用的 PowerShell、CMD、macOS 或 Linux。

   应看到：出现练习场路径。这里的教练不调用付费模型，但文件修改和测试确实发生在练习场。

3. 回车前进，输入 4 跳到差异课；练习拒绝一次、接受一次。输入 q 离开，再运行 koder learn。

   应看到：重新进入时能继续进度；退出默认清理练习文件，进度与文件不是同一回事。

4. 要做自己的项目，离开教程后运行 koder project create "Learning Site" --kind website，再看 koder project list --json。

   应看到：新项目有独立目录。按返回路径打开项目，不猜目录名，也不把教程临时路径当正式项目。

## 故障恢复

- **q 退出后找不到购物车文件**：这是练习场清理，不是作品丢失；需要留存时到毕业课明确选择保留。
- **把 /setup 输入系统终端**：先运行 koder 进入对话，或直接用系统命令 koder setup。
