# 170 · 编辑仓库文案：描述、主页与README

单元 12 · 建议 30 分钟（含自行练习） · 0.4.16 配套教材

[课堂](../index.zh.html#lesson-170) · [总纲](../README.zh.md)

## 学习目标

完成「编辑仓库文案：描述、主页与README」的操作练习，能够解释结果、诊断常见问题并提交可核对的作业。

## 原理讲解

仓库描述适合一句话说明用途，主页链接应指向真实可用页面，README承担安装与使用说明。它们的权限和更新接口不同。编辑前先读取当前内容，保留已有正确资料，修改后读回。文案自然具体，避免把内部任务提示词直接贴进公开仓库。

专题补充
仓库简介承担快速定位，README承担理解、安装和使用，主页链接提供外部入口；三者是独立字段与操作。具体用途和条件比口号有用。编辑应保留已有正确资料并修过时内容，对外主张需要来源，未验证链接与平台不能写成当前可用。

先读当前仓库描述、主页和README，列过时项与应保留内容。分别写一句用途、真实主页入口和可操作README，再按字段核事实与语言。公开文案用自然具体英文，许可证、署名和历史限制不随品牌统一而删除。

## 准备

先完成第169课。使用自有Koder Projects练习目录和合成数据；阅读示例不会执行命令。账号、图形操作和外部写入须另有可用环境与授权；没有条件就记录NOT_RUN。

## 示例与解读

```text
koder github edit OWNER/demo --description "A local task runner" --homepage "https://example.com"

补充案例：一句话简介：从口号变用途
合成仓库现状：description="The best AI thing ever"；homepage=https://example.invalid/old；README含用途、安装、MIT示例许可与第三方NOTICE，安装要求已从Node18变20；工具功能为本地Markdown标题索引，无云同步。任务仅改文案草稿，不修改真实仓库设置。
本课条件：旧描述为The best AI thing ever
```

示例主页必须替换为真实获准地址；未执行只是教学。

## 手把手操作

1. 写下本课目标、当前工作区和预期产物。保留练习原件，在副本操作。

   应看到：目标聚焦「编辑仓库文案：描述、主页与README」，可与本课示例对照；无无关真实资料。

2. 盘点当前介绍

   应看到：标出过时信息。

3. 写具体用途与限制

   应看到：不夸大能力。

4. 按字段确认修改

   应看到：README文件与仓库设置分开。

5. 读回公开或私有页面

   应看到：确认实际生效。

6. 整理本次实际结果与仍未确认的内容，把证据链接到作业。

   应看到：记录与「示例主页必须替换为真实获准地址；未执行只是教学。」逐项对照，不把未执行项填成通过。

7. 提取对象、动作和运行方式，写三版英文简介

   应看到：候选具体说明本地Markdown标题索引，无绝对领先主张

   为什么：简介帮助识别适用性，空泛形容词无法说明能做什么

8. 改变条件：产品增加文本文件支持

   应看到：核已发布范围后更新对象，不把计划功能提前写入

   为什么：建议简介可为“A local Markdown heading indexer.”；README应明确Node20及无云同步，保留原许可和NOTICE。example.invalid仅课堂占位，不能作为真实主页发布。

## 故障恢复

- **结果与示例不一致**：不要删除许可、通知或必要署名以便统一品牌。 先保存原始错误，再从第一次偏离预期的步骤定位。

- **当前环境不能完成真实操作**：完成资料阅读、合成演练和验收计划，标明缺少的账号、运行时或设备。不要伪造回执，也不要为了过课扩大授权。

## 作业

交README修改稿、仓库一句话简介和事实来源。

## 自查与参考答案

至少提交明确产物、关键步骤记录和一项失败或边界检查。结合本课判断题核对：不代表，它们是不同字段与操作。 对真实设备或外部服务没有执行的部分写NOT_RUN。

## 开发者教学

更新设置的UNKNOWN不能自动重复写；保留操作ID与目标。
实现前固定输入、输出、错误与权限契约。为本课关键边界设计一个应通过与一个应拒绝的用例。
交付时记录源码/配置版本、实际命令、退出码、产物及回退方式；静态检查不替代真实账号或设备验收。

开发者加餐
字段更新分别记录before、after、sourceEvidence与operationId。README为文件变更，description与homepage是仓库元数据；一种写入成功不代表其他字段同步。写结果未知时按对应操作对账。
