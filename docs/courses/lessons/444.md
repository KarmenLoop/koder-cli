## 学习目标

完成“交付文本与工具能力矩阵”：写选择建议及证据边界；解释基准与变式的结果。

## 原理讲解

模型说“我要读取文件”只是调用提议。完整往返包括结构化调用、获准执行、带关联ID的结果和模型基于结果续答。工具可以成功而续答失败，也可以文本聊天正常但工具参数不兼容。当前MiMo Token Plan文档标暂不可用，课堂不启用该路线，只用协议事件练习。

本案例的关键推理：编码任务依赖往返，不能只看聊天流畅

操作方法：先将消息按角色排序，检查调用ID、工具名和参数，再把执行结果回填到对应位置。最后核对最终回答是否来自实际结果，而不是模型猜测。用缺ID、错参数和续答失败三个反例测试理解。
