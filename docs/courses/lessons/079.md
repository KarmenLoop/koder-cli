## 学习目标

## 原理讲解

HTML标签表达内容角色。button用于动作，a用于导航，标题有层级，表单字段有标签。用div加点击事件可能看起来可用，却缺少键盘行为和语义。先建立正确结构，再用CSS美化，通常更容易得到可访问、可测试的页面。

## 示例与解读

```text
<main>
 <h1>社区读书会</h1>
 <a href="#signup">查看报名表</a>
 <button type="button">展开活动须知</button>
</main>
```

链接跳转位置，按钮执行动作；标题描述当前页面主题。
