# 025 · 隐私文件带在包里，断网也能看

单元 2 · 建议 25 分钟（含自行练习） · 0.4.16 配套教材

[课堂](../index.zh.html#lesson-25) · [总纲](../README.zh.md)

## 学习目标

找到随包隐私全文，知道任务资料会去哪里，并能最小化分享。

## 原理讲解

隐私不该是一条打不开的链接。CLI 的完整条款、简明声明，以及官网消费者原始全文，都随包提供。CLI 配置文件和桌面加密密钥库不同，说明会分别讲清。

专题补充
隐私说明帮助理解哪些数据被收集、存储和传输。离线随包全文可以在不调用模型时阅读；文件存在不等于用户已经接受所有可选功能。任务资料分享应从完成目标所需的最小片段开始，保留来源和撤销方式，避免把整个用户目录作为方便的上下文。

先列资料类别与用途，再画本机、模型服务和外部应用三个位置之间的数据流。对每次传输写出触发动作和必要字段；用合成姓名和标记练习脱敏，不拿真实秘密试泄漏。

## 准备

使用合成资料学习，不在练习中粘贴真实密码、邮件正文或客户数据。

## 手把手操作

1. 依次查看privacy statement、consumer、sources；记录文档版本/来源。

   应看到：有本机全文，不需要为了看政策先调用模型。

2. 把数据分为项目文件、对话历史、凭据、外部连接回执。

   应看到：每类存储/发送范围分别判断，不能统称“都不外发”。

3. 查看Setup中的资源库、同步、学习与邮件模型读取开关。

   应看到：远端模型收到任务上下文；开关和明确授权控制附加来源。

4. 准备反馈前复制最少错误信息并遮盖令牌、私人路径、邮件和账号信息。

   应看到：反馈仍能复现问题，但不包含不必要个人资料。

5. 为阅读全文和核来源分别选择入口

   应看到：consumer或statement读正文，sources核来源摘要

   为什么：阅读条款不需要调用模型

6. 改变条件：网络断开

   应看到：仍应能读随包内容；不能把网页缓存当唯一来源

   为什么：交件包括数据流图、可分享样本、被移除字段及原因。脱敏后还要检查组合信息是否能重新识别人；哈希和加密的含义不同，不能混称匿名。

## 故障恢复

- **把CLI配置与桌面密钥库混为一谈**：分别阅读对应隐私说明，不把一种存储保证推广到所有产品。

- **卸载后发现数据仍在**：普通卸载可保留数据；删除前确认本机、外置目录与服务器范围。

## 开发者教学

日志与错误体脱敏覆盖嵌套字段、URL参数和异常cause；原始敏感数据不能进入公开回归夹具。
权限撤销、导出与删除要按实际范围验收，不能靠UI开关文本证明。
打包检查包含隐私全文与来源记录，不复制未经许可的第三方资料。

开发者加餐
资源访问范围应由实际权限决定。远端搜索必须明确启用且只发必要关键词；私有资源未命中不能自动降级到公开远端。日志与反馈包也属于潜在数据出口。
