# 01. 开场：欢迎来到 Koder 训练营

建议 25 分钟

**目标**：分清系统终端、Koder 对话与练习场；完成第一次离线练习，并知道作品放在哪里。

**准备**：准备一个可复制粘贴的终端。先阅读安装说明；已经装好则不必重装。练习场是临时目录，毕业时选择保留才会留下文件。扩展作业使用自己的独立目录，不放在安装目录。

## 手把手操作

1. 在系统终端运行 koder --version，记下版本。再运行 koder help。

   **应看到**：能看到实际版本和命令列表；命令不存在时先按第16课排查安装入口。

2. 运行 koder learn；在第一课选择自己正在使用的 PowerShell、CMD、macOS 或 Linux。

   **应看到**：出现练习场路径。这里的教练不调用付费模型，但文件修改和测试确实发生在练习场。

3. 回车前进，输入 4 跳到差异课；练习拒绝一次、接受一次。输入 q 离开，再运行 koder learn。

   **应看到**：重新进入时能继续进度；退出默认清理练习文件，进度与文件不是同一回事。

4. 要做自己的项目，离开教程后运行 koder project create "Learning Site" --kind website，再看 koder project list --json。

   **应看到**：新项目有独立目录。按返回路径打开项目，不猜目录名，也不把教程临时路径当正式项目。

## 常见问题与恢复

- **q 退出后找不到购物车文件**：这是练习场清理，不是作品丢失；需要留存时到毕业课明确选择保留。
- **把 /setup 输入系统终端**：先运行 koder 进入对话，或直接用系统命令 koder setup。

## 作业与自查

交一张学习记录：版本、终端类型、正式项目路径、教程临时路径。说明哪些步骤离线，哪些步骤需要自己的模型。

**自查标准**：四项都能从实际输出查到；learn 的脚本教练离线，普通 ask/run 使用配置的模型。临时练习目录不能当持久交付。

## 开发者教学

1. 建立验收记录：命令、版本、工作目录、退出码、产物路径。

2. 先跑本课程附带的 cart-lab 的 node --test，确认测试发现故意植入的问题；再让 Koder 修复并比较差异。

3. 验收须同时有失败基线、修后测试和文件内容；不要把“模型说修好了”当证据。

4. 教学材料、示例代码与真实账号验收分开记录。

交件要求：按本课步骤选择自有测试目标，保存前置、实际命令/退出码、产物、正反例、未验和恢复方式。使用 [验收模板](../tutorial-labs/acceptance-template.md)。
