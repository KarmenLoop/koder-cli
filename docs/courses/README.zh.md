# Koder CLI 1,800 课中文课堂

0.4.16 配套课程。保留原 180 课、原进度与前 30 课教练，增加 1,620 个中文案例。本次教材构建本身不代表安装或发布。

[进入课堂](index.zh.html) · [使用说明](ACADEMY-GUIDE.zh.md) · [手把手整册](HANDS-ON.zh.md) · [开发者整册](DEVELOPER.zh.md) · [原 30 课 English](index.en.html)

## 学习方式

每个新增案例包含合成输入、任务、五步操作及逐步预期、原因、两个排错入口、变式作业、参考答案与开发者材料。先保留基准输入，再完成操作并核对结果，最后改变条件重新判断。代码示例和文稿练习各按本课说明使用。

120 个单元，每个 15 课。1–180 保留基础；181–1800 是同主题九组独立案例。每个基础课末尾可跳到它的九个案例，适合按主题连续练习。

```text
koder learn 181 --print --track hands-on
koder learn 721 --track developer
koder learn 1800 --print --track all --lang zh
```

旧毕业进度保持原状，可自主选择新课。网页目录每页最多 30 项，搜索覆盖全部课程；可直接输入 1–1800 跳转。阅读、自测、实操分别记录，笔记只存本浏览器，可导出备份。英文教材仍为原 30 课。
