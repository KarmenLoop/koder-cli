## 学习方式

每课有讲解、示例、操作与预期、排障、作业、自测和开发者验证。先阅读，再在自有练习目录操作，最后记录证据。建议30分钟的课时包含练习；单元项目通常预留90分钟。新手顺序学习，开发者重点31–120与151–180，写作办公重点121–150。

CLI：

```text
koder learn 31
koder learn 121 --track hands-on
koder learn 166 --track developer
koder learn 180 --print --track all --lang zh
```

原30课毕业进度继续保留，不强制重学；可直接跳到31。网页阅读、自测与实操作业分开记录，仅保存在本浏览器；可导出备份。现有英文内容仍为原30课，新150课明确为中文。
