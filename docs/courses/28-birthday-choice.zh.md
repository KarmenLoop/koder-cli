# 28. 记住一小格生日，不建立人生档案

建议 20 分钟

**目标**：按用户明确意愿保存最少生日信息，并能查看、更改和关闭。

**准备**：使用虚构月日演练。不需要出生年份、年龄或证件；日常提到他人生日不等于授权记自己的生日。

## 手把手操作

1. 运行 koder help celebrate，查看birthday相关子命令和输入格式。

   **应看到**：按当前帮助操作，避免误把日期当任务文本。

2. 在对话明确说“记住我的生日是三月十四日”，阅读保存提示。

   **应看到**：只保存允许的月日，不推断年龄或身份。

3. 按本课原有命令查看生日状态，修改一个演练日期再查看。

   **应看到**：实际保存值与提示一致，学习/同步开关不被附带开启。

4. 演练结束清除测试生日，保持自动祝福是否开启由自己选择。

   **应看到**：删除与停动画不同；不留下虚构个人资料。

## 常见问题与恢复

- **误记成别人的生日**：明确纠正并查看保存值，不仅让模型说“知道了”。
- **关闭彩蛋后生日还在**：动画偏好与日期记录是独立项，按需要分别管理。

## 作业与自查

用虚构日期完成设置→查看→删除，记录最后状态。

**自查标准**：最终不保留演练日期，不新增年份或其他个人信息。

## 开发者教学

1. 自然语言意图必须区分本人明确记忆请求、引用与他人信息；不从含糊提及自动持久化。

2. 覆盖非法日期、闰日、重复设置与删除；通知应遵守关闭与去重。

3. 隐私删除验证实际存储，不能只改展示文本。

交件要求：按本课步骤选择自有测试目标，保存前置、实际命令/退出码、产物、正反例、未验和恢复方式。使用 [验收模板](../tutorial-labs/acceptance-template.md)。
