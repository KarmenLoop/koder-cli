# 180课课堂使用说明

打开同目录的`index.zh.html`。课堂不用登录、不联系模型、不发送邮件、不上传笔记。数据和脚本随教材包保存在本地；解压时保留目录结构。

## 怎样开始

1. 新手从第1课开始，原30课内置教练完整保留。已完成基础课的用户可直接在搜索框输入主题或跳第31课。
2. 左侧按12个单元选择，每单元15课。网页一次显示一课，上一课/下一课和浏览器前进后退均可导航。
3. “全部教学”包含手把手和开发者内容；两个独立按钮可以聚焦一条路线。切换不会删除笔记。
4. 先读讲解和示例，再在自己的练习目录执行。示例可能是命令、配置、伪代码或任务提示，复制不会执行。
5. 选择自测答案后查看解释；错误答案不会增加答对数量。打开解释和复制答案不等于掌握。
6. 完成后分别标记“已阅读”和“已完成并自查实操作业”。两者与自测答对各自统计，课程勾选不是能力认证。

## 笔记与恢复

笔记仅在当前浏览器存储。它与CLI会话、记忆、账号和其他浏览器不同步。不同浏览器对file地址的存储支持可能不同；存储被禁用或满额时页面提示导出，不会静默声称已永久保存。

“导出进度与笔记”生成JSON文件；“导入记录”只读取受限结构，不执行代码。导入合并已完成状态，不清除已有记录；同课不同笔记会合并，单课上限10000字符。不要把密码、Key或私人邮件正文写入课堂笔记。

清除记录需要确认，只影响本浏览器课堂状态，不清除CLI会话或学习进度。建议清除前导出。打印当前课可保存个人阅读副本，完整手把手和开发者教材另有Markdown整册。

## 与CLI安装包的关系

180课课堂随 Koder CLI 0.4.12 提供，支持 `koder learn 31`、`koder learn 180 --print` 和 `--track hands-on|developer|all|overview`。旧安装包请先升级；打开网页不会替你升级程序。

原有进度格式保持，已完成基础30课的用户不会被强制重学。新增150课为中文，原30课英文内容保留；不宣称已经完成180课英文翻译。

## 教学完成与环境验收

本地脚本、模拟API、真实模型、真实账号、Windows图形操作和正式部署分别验收。缺少账号或设备时完成计划和合成演练并记NOT_RUN。课堂不自动装软件、不修改系统权限，也不会代替最终发信或发布确认。
