# 180课课堂接入说明

本文件说明 Koder CLI 0.4.12 内置课堂的静态托管方法；课程版本 `academy-180-v1`。实际发布地址与验证范围见本版发行说明。

## 本地与网页

完整离线包保留`docs/courses/`、`docs/tutorial-labs/`和引用文档的位置。入口为`docs/courses/index.zh.html`，脚本、样式和数据均从同目录`academy/`加载，无CDN、登录或模型依赖。网页显示一次一课，可以按单元、关键词和学习状态查找。

静态托管可原样部署教材目录，例如放在网站的`/academy/`根目录下，课堂入口变成`/academy/docs/courses/index.zh.html`。这样相对链接无需改写。若要使用更短路由，由网站构建器改写所有资源和讲义路径，并重新执行链接验收；不要只移动一个HTML文件。

官网入口文案可使用：“180课中文课堂：12个单元，含手把手、开发者讲解、练习、自测、作业和本地笔记。原30课英文教材保留。”不能写“180课完整英文版”，也不能把课程勾选说成技能认证。

## 与既有官网课程渲染器对接

`website-cli-tutorials.json`沿用`editions`字段，增加/保留以下显式信息：

- `version`：0.4.12发行版。
- `count`：180，表示中文完整课程数。
- `languageCounts`：`zh:180`、`en:30`；渲染当前语言必须读取这个值或数组实际长度。
- `status`：`published`，表示随发行包提供。
- 四种Shell版本：`powershell`、`cmd`、`mac`、`linux`。

不要让英文页面根据全局count循环180次后显示150个空白课程。新150课在CLI英文环境中明确标注为中文内容；本轮没有伪造翻译。

## CLI

复用原`learn`入口、LESSONS、CURRICULUM与进度格式，新增课号31–180。已有用户完成原30课后仍保留完成状态，不强制重学。原第30课ID`graduate`及旧练习保留，标题说明这是基础训练结课。

使用示例：

```text
koder learn 31 --print --track hands-on --lang zh
koder learn 151 --print --track developer --lang zh
koder learn 180 --print --track all --lang zh
```

以上命令要求运行0.4.12及后续版本；旧安装包不会因打开网页而自动获得180课。不要将候选教材说明冒充安装更新已生效。

## 发布时检查

1. 固定发布内容与哈希，保留旧30课包作回退。
2. 检查180课目录、12单元、课程引用、讲义下载和所有本地资源。
3. 在实际浏览器检查宽/窄视口、键盘、笔记保存、重新打开、导入导出和打印。DOM模拟结果不替代视觉验收。
4. 确认HTTP与file环境的存储差异有提示；测试存储不可用时导出路径。
5. 修改官网导航、课数、介绍和教程入口；从线上读回HTML、数据与ZIP哈希。
6. 若同时发CLI包，分别验收候选入口与安装后的实际版本；不把静态课堂上线等同于Windows/macOS安装通过。

## 回退

课堂数据使用独立键`koder-academy-180-v1`，不写CLI配置。移除候选入口可回到原30课页面；先让学员导出笔记。CLI恢复原源码/旧包时原进度格式不变。不要清除用户会话、项目、邮件或系统权限。
