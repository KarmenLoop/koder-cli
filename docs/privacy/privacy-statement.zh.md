# Koder CLI 隐私声明

2026-11-01 候选补充：本机自检只读取当前 Koder 数据目录。独立脱敏错误投影默认设为开启，但要求首次交互说明、登录与专用服务就绪；CI 不自动上传，不补传旧历史。Setup 或 `koder setup diagnostics off` 可关闭，本地遥测 off 同时停上报。排除原始对话、文件与路径、邮件正文和凭据。反馈须脱敏预览并明确确认，请自行核对自由文本中的剩余私人信息。本机私有队列最多 100 条错误与 20 条反馈，处理时清理超过 7 天的项目；没有其他用户或云端日志查询接口。目前专用生产授权与 HTTPS 入口尚未接通，未开启生产收集。字段、账号绑定、存储、服务器保留期候选与验收限制见[自检与上报](../DIAGNOSTICS.zh.md)。网络基础设施可能收到通常的连接元数据。此前原始日志不上传和手动邮件说明不包含此独立候选投影。

基本本地使用免费，不强制会员。正常任务会把你提交的消息、必要历史和实际读取的文件/工具结果发给你选择的模型；请先核对服务方、套餐、地区及数据规则。CLI 的本地 API 配置与环境变量不等于桌面加密密钥库。没有主动开启的偏好学习、同步和电脑权限，不会因为同意许可而开启。

生日只在明确选择后保存月日；可随时删除。普通提及只提示选择，明确“记住我的生日”才可本地保存。他人生日不作为你的生日。语言学习是可选本地计数。节日提示、约六秒动画和音乐可分别关闭或跳过，拒绝这些功能不影响正常任务。

默认不做 IP 地区查询，也不打开生日音乐。查询地区需要单独确认，ipapi.co 会收到公网 IP；本机只存国家代码。生日音乐另行开启后，一天最多自动打开一次浏览器页；默认旋律在本机生成。你选择或点击外部音乐平台时，才会把正常访问数据交给该平台。浏览器可能要求点击播放，不会被绕过。

反馈只提供邮箱和空白模板，不自动发送或附加历史。官网与内核介绍只展示公开能力；应用权限、确认、脱敏和校验不能替代操作系统防护，也不能承诺安装在设备上的代码绝对无法被提取。

完整消费者隐私条款：koder privacy consumer。官网原始消费者声明与协议：koder privacy desktop / agreement。来源及文件 SHA-256：koder privacy sources。生日删除：koder celebrate birthday forget；关闭音乐：koder celebrate music off；关闭自动提示：koder celebrate auto off。全部全文随安装包离线提供。


执行审批设置仅保存在本机 execution-permissions.json，按宿主与工作区限定；规则保存动作哈希、风险类型和时间，不保存原始命令或密钥，也不作为共享记忆同步。默认智能判断允许低风险检查与普通项目修改；敏感操作询问并可选择始终允许。全面开放必须明确选择，可覆盖当前项目或显式选择全部项目；它能运行代码、改删文件和使用已有应用授权，不授予系统权限或代填密码。permissions execution status 可查看，revoke/reset 可撤销。严格思考模型的私有续答状态仅保留在当前工具循环；恢复旧历史时使用有限的可见历史引用，不伪造或持久化隐藏推理。


官方远程资料：本机 CLI 任务可按需读取已获许可的工作流。官方服务接收简短检索词、选中的资源编号、偏移和长度；客户端不会附加整段对话、模型密钥或本机私有合集。托管基础设施会接收 IP 等通常的网络元数据；资料处理程序不记录查询和正文日志。选中的片段与必要版权声明会进入任务模型上下文，也可能保存在任务历史中。启动时不下载整库。设置 KODER_REMOTE_RESOURCES=0 可关闭。本机私有合集不会回退到远程搜索。GitHub 只保存加密资源，密钥仅在官方服务端；已交付的明文片段仍可被用户保存。许可不明材料不开放。详情见 docs/REMOTE-RESOURCES.md。
