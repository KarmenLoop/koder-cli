# Koder CLI 消费者隐私条款（完整文本）

更新与生效日期：2026 年 10 月 20 日。适用版本：0.4.0-preview.15 起。
提供方：KARMENLOOP 官方团队，所在地：中国上海。联系：info@karmenloop.com。官网：https://karmenloop.com。

## 1. 适用范围与选择

本条款说明 Koder CLI / TUI、本地 KARMEN LOOP 任务内核、安装与更新、可选连接和庆祝功能如何处理信息。个人非商业本地使用免费，商用须另获书面授权，可以自接模型 API；接受使用许可不等于同意学习偏好、同步、电脑权限、地区查询或音乐。跳过或关闭可选功能不影响正常任务。模型服务、音乐网站、IP 地区服务、操作系统和其他连接方各自适用其条款。

安装包同时保留官网最新消费者隐私声明及使用协议的完整原文，可用 koder privacy desktop / agreement 离线查看；来源和摘要在 koder privacy sources。原文含桌面应用专属描述，例如加密密钥库和剪贴板行为。CLI 的具体行为以本条款、CLI 隐私声明及当前实际设置为准，不把桌面实现当作 CLI 的保证。

## 2. 本地信息、用途与保存

对话、模型回复、工具调用及结果、审批和恢复记录用于完成并继续任务。CLI 将启用的记忆保存在当前配置的本地目录；--no-memory 关闭该次会话的持久记忆，已有设置及显式开启的独立功能不因此自动删除。工作文件由用户选择的项目和单独授权范围决定；读取的内容可能成为模型上下文。

模型名称、接口、限额和密钥来源用于访问用户选择的 API。CLI 支持本地模型配置文件及用户明确设置的环境变量；配置文件中的 API Key 不应被视为桌面加密密钥库。CLI 对保存文件使用用户级权限，部分连接凭据通过系统凭据存储或加密设施保存，实际可用性可在对应诊断中查看。请妥善保护本机账户、备份及环境变量。

设置、教程进度、界面语言、主题、已读节日提示及可选庆祝偏好用于保持本地体验。生日仅保存明确确认的月日，不索要出生年份、姓名、证件或年龄。普通生日提及只提示选择，明确要求记住自己的生日才可本地保存；他人生日不作为本人的生日。可选常用语言学习只累计中文/英文消息次数，不另存原文；选择固定语言会停止该学习并清除计数。

本机信息保留至用户清除相应记录、关闭并删除相应功能数据或移除配置目录；会话、项目产物和用户自行备份需要分别管理。卸载程序不保证删除用户选择保留的文件。节日已读标记避免重复打扰；生日删除同时清理生日页面及相关本机标记。

## 3. 模型和外部连接

发送任务时，用户消息、所需历史、读取到的文件和工具结果、任务指令以及必要的 API 凭据会提交至用户选择的模型接口。服务方会看到网络请求来源。不同厂商和套餐的数据使用规则不同；例如阿里云 Token Plan 个人版与团队版的条款并不相同。请在配置前核对服务、地区、套餐、密钥、数据规则及费用。Koder 不保证第三方账号额度或模型持续可用，也不会为了兜底而自动换到另一计费通道。

通过用户连接的应用、MCP、消息渠道或网页工具发起的请求会把对应功能必需的内容交给该接收方。连接、启用、共享和外部写入是不同选择；应用授权不替代工具审批。stdio MCP 和用户配置的本地引擎会运行本机程序。第三方本地程序的权限与影响需独立核对。

## 4. 可选账号、共享和学习

基本使用不强制注册 Koder 会员。账号登录、跨设备或渠道共享以及个性化功能只有用户明确配置并开启时才运行，具体范围、接收服务及保留方式显示在对应设置中。API Key 和执行批准不作为普通记忆同步。跨端内容、群聊/私聊身份边界和主动联系各自有权限要求；不能从历史记录中恢复已经失效的批准。

生日、庆祝偏好和语言计数保存在独立的本机 delight 设置中，不主动加入模型上下文或记忆同步。用户在正常消息中自行输入的生日或其他内容，仍适用第 3 条的模型提交规则。没有开启单独的学习或同步，不会因看到生日祝福而开启它们。

## 5. IP 辅助地区与音乐

默认不调用 IP 地区服务。明确选择 koder celebrate locale --ip 并确认 IP 后，CLI 会向 https://ipapi.co/country/ 发出一次请求。该服务因此收到公网 IP 及必要的连接信息；本机只保存两字母国家/地区代码，不保存 IP、城市或精确位置。IP 地区可能因 VPN、出差和网络出口而不准确，仅作节日地区和语言的弱提示。用户明确语言及已开启的常用语言计数优先。

生日音乐默认关闭。明确开启后，用户在生日使用交互对话时，Koder 可请求浏览器打开一个生日音乐页；同一天自动请求最多一次。默认页面及旋律在本机生成，不访问音乐平台。用户选择 QQ 音乐或 YouTube Music，或点击页面中的外部链接后，该平台会接收 IP、搜索词和其自身会处理的访问数据，可能要求登录、会员或点击播放。浏览器可能阻止自动播放；页面会保留一键播放及停止，Koder 不绕过浏览器限制、不承诺自动有声播放。

IP 查询和音乐各自独立；同意其中一项不等于同意另一项。第三方政策：https://ipapi.co/privacy/、https://y.qq.com/、https://music.youtube.com/。

## 6. 安装、更新与公开信息

安装及显式更新会访问官网、GitHub 发布或其必要的官方分发地址，下载说明、校验清单、程序和需要的 Node 运行时；这些服务器可见 IP 和正常下载请求信息。程序默认不把对话、文件、密钥或生日发送给 KARMENLOOP。安装介绍只使用公开产品与内核能力说明，不展示私有实现、凭据或运行日志。动画不改变安装验收、许可和校验流程。

## 7. 防护与边界

CLI 使用权限范围、独立确认、主机侧工具审批、路径/输入检查、敏感信息脱敏和下载 SHA-256 校验等防护；这些是应用控制，不替代操作系统防火墙、磁盘加密或终端安全。不会因许可同意、--yes、网页内容、模型回复或旧记录而自动扩大授权。内部备用引擎默认禁用，不自动切换。任何软件都不能保证零漏洞；用户设备上的运行包也不能保证无法被设备所有者提取。

## 8. 反馈、联系与披露

检测到明确反馈或联系意图时，Koder 提供邮箱及空白反馈模板，不自动发邮件或附加历史。只有用户自行选择发送的内容会进入邮件服务。发送前请删除密钥、密码、私人路径和聊天记录。我们只按处理该反馈所需的范围处理实际收到的信息，不将其用于定向广告。法律要求或依法有效请求涉及的信息，仅以我们实际持有的内容为限。

## 9. 您的权利与撤回

可通过本机设置和文件查看、复制、更正或删除自己的信息；模型配置、会话、共享、应用连接和操作系统授权需要分别处理。koder celebrate birthday forget 删除生日并关闭音乐；koder celebrate music off 停止后续自动音乐；koder celebrate auto off 关闭自动节日提示；koder celebrate locale --language zh（或 en）停止常用语言学习。可移除本机 delight 目录以清除该功能全部记录。撤回不影响已经完成的处理，第三方已经收到的信息须向相应第三方申请处理。

## 10. 敏感信息、未成年人和跨境

请勿提交无权处理的个人信息、机密、身份证件、金融、健康、精确位置或儿童信息。产品不需要生日年份或年龄。未成年人应在监护人指导下使用，未满十四周岁者不应自行提供个人信息或开启外部连接。选择境外服务或访问境外网站可能使必要内容传到境外，请先核对自己的权限及接收方政策；未启用的可选功能不会因该选择自动开启。

## 11. 变更与联系

功能、接收方或处理目的发生实质变化时，更新日期和说明会随版本展示；需要另行选择的功能保持独立确认。隐私问题、访问、更正、删除或投诉可联系 KARMENLOOP 官方团队，info@karmenloop.com。请只提供定位问题必需的脱敏信息。我们依适用要求处理请求，官方消费者声明中的投诉和联系安排仍可查阅。


执行审批设置仅保存在本机 execution-permissions.json，按宿主与工作区限定；规则保存动作哈希、风险类型和时间，不保存原始命令或密钥，也不作为共享记忆同步。默认智能判断允许低风险检查与普通项目修改；敏感操作询问并可选择始终允许。全面开放必须明确选择，可覆盖当前项目或显式选择全部项目；它能运行代码、改删文件和使用已有应用授权，不授予系统权限或代填密码。permissions execution status 可查看，revoke/reset 可撤销。严格思考模型的私有续答状态仅保留在当前工具循环；恢复旧历史时使用有限的可见历史引用，不伪造或持久化隐藏推理。

## 本机私有资料库

选定 ZIP 的参考资料加密保存在本机 private-resources 目录，与账号记忆同步分开；导入不运行脚本或公开原件。默认关闭模型检索；--model-access 或 allow-model ... --confirm MODEL 才允许本机任务搜索目录，并把选中的片段发给你配置的模型服务。网关与 ACP 不自动获得此库。disable 关闭后续读取，无法追回已发送的内容；remove 只移除目录关联，保留加密对象和原 ZIP。商业授权洽询与 GitHub 点星均为可选，不会自动发消息、打开浏览器、创建仓库或授予权利。


官方远程资料：本机 CLI 任务可按需读取已获许可的工作流。官方服务接收简短检索词、选中的资源编号、偏移和长度；客户端不会附加整段对话、模型密钥或本机私有合集。托管基础设施会接收 IP 等通常的网络元数据；资料处理程序不记录查询和正文日志。选中的片段与必要版权声明会进入任务模型上下文，也可能保存在任务历史中。启动时不下载整库。设置 KODER_REMOTE_RESOURCES=0 可关闭。本机私有合集不会回退到远程搜索。GitHub 只保存加密资源，密钥仅在官方服务端；已交付的明文片段仍可被用户保存。许可不明材料不开放。详情见 docs/REMOTE-RESOURCES.md。
