# Koder CLI 0.4.16

本版补齐 0.4.15 的自寻工具和子任务交接。Windows CMD、PowerShell 与 macOS 安装器使用同一版本化运行包。运行 `koder update`，随后用 `koder --version` 核对 `0.4.16`。

## 本次增量

1. **先找本机工具**：`koder tools seek node --local --json` 只检查 PATH 中的文件，不联网、不安装、不执行。默认发现已安装工具后先返回；缺失时仍按原网络授权检索。
2. **Todo 真正交给子任务**：分配的项目及内部依赖进入子任务自己的计划；外部前置项未完成、同项重复分配时明确拒绝。父任务显示负责人，核对文件和回执后再标记自己的项目完成。
3. **完整收回计划**：子任务 Todo 和现有回答、工具回执均可分页收集，翻页无需重新运行任务。
4. **独立查询检查点**：`koder subagents status --json` 不抢占聊天锁；旧 running 记录显示 `unconfirmed`，不会假称当前还在运行。实时状态和取消仍使用当前聊天中的 `/subagents`。
5. **Skill 命令衔接**：`/skill seek` 与 `/skills seek` 行为一致；fetch 后重载当前会话技能库。只读目录不再无谓初始化电脑权限运行时。

默认工具/模型轮次继续不限，保留取消、父子共享金额预算、审批和 UNKNOWN 核对。每个根任务仍最多 180 个已创建未释放子任务；文本、路径和传输保护仍有效。现有 1800 课中文课堂、原 30 课英文教材、邮箱、GitHub、MCP、迁移与历史均保留。
