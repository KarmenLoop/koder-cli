# Koder CLI 0.4.11

Connect your own GitHub account from Setup or koder github connect. The built-in connection can list and read repositories, create private repositories, commit selected project files, edit repository descriptions and homepages, and open draft pull requests on existing branches.

GitHub operations are available directly to the Agent through github_read and github_project. A selected-file commit uses the current workspace's contents, preserves other files, and refuses a force update. Tokens use the existing protected local credential store. Each remote write shows its target and content for confirmation; --yes does not substitute for that approval.

Interrupted writes retain a receipt for reconciliation instead of being blindly repeated. Confirmed remote work now satisfies the repository-delivery check without requiring unrelated local code files. Ordinary coding tasks keep their existing file and test requirements.

## Install and learn

Windows CMD/PowerShell and macOS installers use the same versioned runtime. Run koder update, then verify koder --version reports 0.4.11. Older updaters that reject the manifest can use the current [official installer](https://karmenloop.com/download.html).

## Verification and limits

The final source regressions passed 72 CLI checks and 23 GitHub/kernel checks. They use loopback responses, a protected-storage test port and a scripted provider; they do not prove live GitHub PAT, organization or model acceptance. Actual package checks are recorded separately in the handoff.

Native Windows 10/11, PowerShell 5.1 cold startup, ConPTY/IME, Windows-MCP GUI, real mailbox/provider accounts and native credential stores remain unverified. Two earlier input-interaction failures remain in the historical evidence. The separate unsigned macOS locked-use prototype is not included.

This first GitHub connection does not implement browser OAuth, GitHub Enterprise, binary/LFS upload, whole-directory upload, branch creation, merge, deletion or GitHub Projects boards. It supports selected text files and existing branches; see the guide for limits and token permissions.
