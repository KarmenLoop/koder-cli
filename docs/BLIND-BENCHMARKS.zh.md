## 可重复的流程检查

```sh
node scripts/check-contracts.mjs --list
node scripts/check-contracts.mjs --kernel /已授权的私有内核路径
```

在已有的私有验收工作区中，使用相互匹配的候选 CLI 与内核。这个入口不安装依赖，移除测试环境中的模型凭据变量，并使用单个 worker 与原有 60 秒文件上限。测试模型和本地端点只验证流程，不调用付费模型。`--list` 先显示命令、题目哈希和缺失材料；临时目录会打印出来，便于保留排障资料。

源码接入并取得 CI 运行授权后，可把这个命令放进私有仓库的 nightly。当前未创建定时作业、触发付费模型调用或启用公开工作流；nightly 流程检查也不能冒充真实能力评测或 Windows 真机验收。
