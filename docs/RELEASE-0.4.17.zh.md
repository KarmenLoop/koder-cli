# Koder CLI 0.4.17 更新与核对

Windows 和 macOS 使用同一版运行包。运行 `koder update`，重新打开终端会话，再用 `koder --version` 确认 `0.4.17`。若网络阻断 GitHub，可从官网安装页使用对应系统入口。

## 本次具体修复

1. 修复、审查后修复、生成测试的任务，不再因为结尾“说明改动”或报错中提到邮件而误入文稿门禁。配置了检查命令时，由原工作流在落盘后执行并核对退出码；UNKNOWN 与取消仍会阻止继续。
2. 小上下文模型按实际发给服务商的工具 schema 计算空间，排除仅供本机宿主使用的元数据；原始历史与工具配对记录保留。
3. 旧会话没有子代理字段或任务 ID 时，恢复核对不再崩溃；旧 unknown 回执不会自动变成成功。
4. 预填草稿在常驻输入区绘制前写入，折行和光标按草稿实际内容定位；选择后仍需用户编辑或按回车发送。JSON 不再多发一个空 Todo 事件。
5. 交付检查回收已经完成的调用记录，连续 600 次工具返回后仍可接受后续实际文件交付，不再在 256 次完成调用后误判为回执不足。费用预算、取消、并发和资源边界保留。
6. 竞品价格需要本轮实际读取官方页面，并引用短原文及对应 URL；裸链接、失败读取、改价或编造套餐仍拦截。诚实说明“不确定/公开信息有限”可继续；没有重跑真实模型评分。
7. Harness 成功执行观察保存在原会话检查点，可用 `koder harness experiences --json` 查看。没有配对执行对照时仍标记 `NO_ENTRY`，不会自动采用新方法；移除经验入口遗留的 24 步限制。
8. 修正更新回退地址和安装器的旧版本引用，保留中文 1800 课、原英文 30 课及八套终端教材；当前指南不再写“最多四个 Skill”。

9. `koder model presets --json` 返回真正的 JSON，包含可选、暂不可用数量和账号未验标识；内置教练恢复先失败、再修正、由 fix 独立复核的两轮演示。

## 手把手核对

```text
koder --version
koder model presets --json
koder harness status --json
koder harness experiences --json
koder skills list --limit 200
koder mcp list
koder notifications status
koder status
```

交互会话：空输入按 `/`，选模板后确认没有直接发出；长任务时输入补充，切换 Setup 的引导/排队模式；按 Esc 停止。修复任务用 `koder fix --check "你的检查命令" --yes -w "测试项目目录"`，检查通过必须来自真实退出码。测试只在独立副本操作。

工具默认不限轮次，可用 `koder harness steps unlimited` 恢复。费用上限需填写自己服务商的真实单价：`koder harness budget <金额> USD|CNY <模型> <输入每百万价格> <输出每百万价格>`。不确定费用不能当成零；关闭预算不会获得额外电脑权限。

## 验证边界

本轮完整 CLI、相关内核、安装包和公开下载的检查分别留有命令、退出码与结果；初次失败记录保留。源码与本机隔离检查不代表 Windows 实机或真实邮箱/GitHub账号已经通过。你们的 beta 专员继续在官网下载后检查 Windows 10/11 无 Node 冷启动、更新、输入与 MCP 图形操作，本轮按用户授权发布。macOS 锁屏原生组件仍为未签名候选；没有 Developer ID 和专用锁屏设备时不能宣传为完整正式支持。
