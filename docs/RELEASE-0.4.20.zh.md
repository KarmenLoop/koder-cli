# Koder CLI 0.4.20

本版把 Awesome LLM Apps 接入 CLI 默认 AI 应用工作流。沿用原模型、工具与审批，从选参考、读源码、制定实施步骤，到检索项目资料、核对引文和实际交付。

## 新增内容

- 固定上游提交 6c16b23f1bacd0fdf240bb5141ef45e59e82c306，内置146个应用/教程条目、1,636个文本资源及许可证、哈希。
- 7项 Koder 改写方法：项目复盘、读者反馈、改动范围、代码历史、依赖体检、口述整理、顾问与执行分工。
- 5个真实可调用工具：目录、源码、规划、本地词法检索、逐字引文核验。
- koder llm-apps 命令、Setup 单项/总开关；相关任务默认接入，原权限、BYOK、费用预算、取消、记忆隔离和不限工具轮次继续保留。

[手把手教程](AWESOME-LLM-APPS.zh.md)包含无需模型即可练习的检索、真实哈希引用、伪造引用失败和来源更新检查。[目录](AWESOME-LLM-APPS-CATALOG.md)列出全部条目。

关闭：koder llm-apps off；开启：koder llm-apps on。重开会话生效，单独关闭的子方法不会被总开关覆盖。

## 验证与边界

CLI相关回归125项通过，覆盖长任务、邮箱、MCP、Skills和原生SolidCraft。底层回归先发现一个旧的技能来源断言：原插件已保留 bundled 来源，但旧测试仍期待 Hermes。已改为分别核对 Hermes 工具和原内置技能，56项通过，原失败记录保留。新增测试覆盖主开关在目录和插件注册两条路径的效果。

脚本化模型已通过真实工具读取资料、核对引用、按原审批写报告；拒绝审批不会写入。越界、凭据、链接、伪造引文和文件变化均有检查。这不等同于真实付费模型能力评分。

146条是固定参考，未批量安装或运行上游全部服务。外部SDK、语音设备、数据库、UI和账号需要按项目配置并实测。Windows/Intel Mac真机验收交给beta团队；原Windows图形、真实账号、未签名Mac锁屏组件等NOT_RUN保持。

本版仅同步GitHub的运行包、Windows/macOS安装器、教程和更新信息，官网不改动。安装包的私有运行源码与公开历史源码仍分别标明。
