# Koder CLI 0.5.10

macOS and Linux installations now select smaller platform archives automatically. The installer resumes interrupted downloads across retries and later invocations, recovers when a server refuses Range, and verifies the entire file before activation. Users keep the same installation and update commands. The complete offline archive remains available.

Supported features, active Skills, current classroom content and selected OCR models remain included. The reduced archives leave out foreign-platform executables and duplicate historical tutorial exports. Build-only OCR data-package copies are removed while the actual English and Simplified Chinese model bytes remain unchanged. [Installation and recovery guide](DOWNLOADS.md).

This release includes the previously unpublished 0.5.9 changes: Personal Agent Growth 0.4.3 loads bounded source excerpts by default, typed native learning writes use current evidence, complete saved constraints take priority in small context budgets, and read-only delivery verification is available during continuation. Existing off switches, approvals, cancellation, provider routes and UNKNOWN handling remain in force. [Learning guide](MARKDOWN-LEARNING.en.md).

The 0.5.9 draft was held when download reliability became the release priority. Earlier failures remain in the acceptance record. A prior first-model startup benchmark remains above its original 1000 ms threshold on this host; it is not relabeled as passed. Windows physical testing stays with the beta team. Ubuntu runner, local installation, source tests and provider exercises have separate evidence scopes. Signed macOS lock-screen operation remains an unsigned candidate. The website is unchanged.

See `ACCEPTANCE-RESULTS.json` and `SHA256SUMS` in this release for archive identities, checks and remaining limitations.

Ubuntu 24.04 has a dedicated installer link. Local Skill discovery now retains metadata and checksums instead of full instruction bodies; on-demand reads and change detection remain intact.
