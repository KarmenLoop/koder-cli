# Koder CLI 0.8.1

> **0.8.1 发行草稿。** 官网尚待发布；主分支保留已发布的 0.7.2 内容。实际可用版本请以[官网下载页](https://kodermodule.com/cli-download.html)为准。

[English](RELEASE-0.8.1.md) · [简体中文](RELEASE-0.8.1.zh.md)

0.8.1 是 Koder 的产品整合发布版：把任务内核、浏览器与数据采集、上下文管理和受管运行组件收成一套可安装、可学习的工作流程。沿用 0.7.2 已交付的实现，同步更新 Windows、macOS、Ubuntu 安装入口和本版教材，并补齐自研模块与开源组件的来源说明。版本升级本身不代表新的模型评分。

## 一句话到任务交付

Koder 自研任务内核连接目标、计划、模型路由、工具调用、持久回执和交付检查。子任务使用稳定请求编号去重；追加要求交给原 Worker；结果事件唤醒主任务；子任务写出的文件也进入父任务交付核验。沿用同一取消、权限与费用预算，不重复启动另一套执行器。详见[任务编排](TASK-ORCHESTRATION.zh.md)与[架构和来源](ARCHITECTURE-AND-PROVENANCE.zh.md)。

## 浏览器和数据采集

Web Data 支持 CSS、XPath、结构指纹自适应、动态页面渲染、记录保存与证据追溯。浏览器交互复用既有工具，支持导航、点击、填表、键盘、框架、标签页、截图、PDF 和经授权的文件传输。自适应仅使用同源、已校验的原任务信息；匹配有歧义时保留部分结果。详见[数据采集教程](WEB-DATA.zh.md)。

## 长上下文、运行组件和学习

上下文预算、压缩和历史检索保留原始回执。FFmpeg/ffprobe、Playwright、EARSHOT、CodeGraph 走受管安装与诊断，缺少平台依赖或音频模型时说明具体要求。Skill 商店复用现有下载、检查和适配流程。保留 79 个唯一 Skill 注册及当前课堂，不把旧版教材重复塞入运行包。详见[上下文](CONTEXT-CONTROLS.zh.md)、[运行组件](TOOL-RUNTIMES.zh.md)与[Skill 商店](SKILL-STORE.zh.md)。

## 安装与升级

Windows、macOS、Ubuntu 均从 [CLI 官网](https://kodermodule.com/cli-download.html)选择安装方式。已有用户运行 `koder update`，随后运行 `koder --version` 核对。下载进度、断点续传和摘要检查继续保留。[完整用户指南](USER-GUIDE.zh.md)覆盖安装后如何进入 CLI、登录、配置模型和学习命令。升级保留配置、历史、项目文件与已有授权。

Koder 的任务编排、权限控制和交付逻辑由团队自主研发，并在私有内核中维护；安装包同时集成经适配的开源运行组件与资源，按各自许可保留来源和署名。这些依赖不标为 Koder 原创，也不表示获得第三方项目背书。

0.8.1 的实际包检查见 ACCEPTANCE-RESULTS.json。前版真实模型和浏览器证据保留原版本标记。Windows/Ubuntu 原生安装与图形操作、生产真人登录、真实邮箱、可见系统通知、小时级长任务和考试质量分别验收，不因发布版本变更自动算通过。

## 发行核对与未验范围

0.8.1 冻结构建记录包含 44 项源码发行检查，以及解压后实际包的 348 项检查（299 项 CLI、49 项内核）。两组分别记录，不是新的模型质量分数。另记录 14 项 macOS 命令检查和一次隔离安装：复用已有兼容 Node，通过自有本机回环镜像安装。这不能证明公网下载或其他系统无 Node 冷安装已通过。

运行文件比对得到 20,760 个文件未变，版本文件另计；79 个唯一 Skill 注册项及 8 份许可/署名文件与 0.7.2 一致。本里程碑整合已有实现、安装器和文档，不替换执行器，也不把所有包内依赖称为 Koder 原创。

一次有界 MiniMax-M3 任务和 19 项 macOS 浏览器检查均运行于 **0.7.2**，**未在 0.8.1 重跑**。模型任务使用合成本地数据和进程内账号夹具，浏览器矩阵使用自有本机页面；这些不代表正式服务认证、全部浏览器、小时级任务或基准成绩提升。

Windows/Ubuntu 原生安装与 GUI、正式服务真人登录、真实邮件、可见系统通知、小时级任务及 MiniMax-M3.1-Flash 基准质量仍为 **NOT_RUN**。[验算记录](AGENT-VERIFICATION.zh.md)保留早期失败。原 0.7.2 Mac 下载超时仍见[对应发行记录](RELEASE-0.7.2.zh.md#发行核对与未验范围)，独立机器通过不能证明该 Mac 网络已恢复。

**官网发布待完成。** 冻结构建有 32 个原始文件，共 1,111,623,159 字节；构建回执不能证明网站激活、普通公网 HTTPS 下载、Range/续传或正式更新器已经通过。收到官网负责人完整交付记录后，才能把这份草稿改为当前正式版。
