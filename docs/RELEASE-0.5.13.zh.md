# Koder CLI 0.5.13

修复 GTK4 控件可用但没有操作按钮的问题：按 GTK4 的实际敏感状态识别，禁用控件仍不可操作；已声明密码及遮罩输入不向模型返回内容或操作入口。

新增 Ubuntu 26.04.1 Desktop amd64 适配路径和独立安装入口，复用完整 Linux 运行包。中文完整教程区分 Wayland、系统依赖、桌面授权与实际调用，并覆盖首次启动、升级与故障处理。24.04 支持继续保留。


Ubuntu/macOS 安装结束后现在明确打印可立即使用的完整启动路径、配置命令和当前终端 PATH 命令。Bash 新用户目录与已有登录配置都会按实际路径更新，保留旧内容；后台激活说明明确区分服务与聊天。Ubuntu 教程补齐全部安装问答、状态 JSON 解释、首次对话、交付检查和故障定位，首页与完整用户指南同步。

打包时排除 macOS 扩展属性，避免 Ubuntu 解压刷屏 `LIBARCHIVE.xattr.com.apple.provenance`。保留程序、Skills、OCR 数据和课堂文件。新路径回归覆盖尚无 shell 配置、旧 PATH 标记、自定义目录和不修改 PATH 模式。

本版优化默认自主学习的启动开销：同一事务阶段写入同一目录的多份文档时，合并重复的目录同步。每份暂存文档、正式文档和事务日志仍单独同步；先确保持久暂存，再记录 prepared，正式文件及目录持久化后才写 committed。恢复时核对已有文件，不重复写入已完成的结果。

自主学习仍默认开启，61 份 Personal Agent Growth 资源、现有 Skill、项目隔离、检查点、取消和费用预算均保留，不删减功能。

本机 macOS 隔离对照使用新用户目录和本地模型 API：0.5.12 首次请求耗时 1094.2、973.1、957.7 毫秒；仅替换学习存储后的候选为 891.8、878.5、854.8 毫秒。这是单机启动测量，不代表真实模型生成速度或质量，也不保证所有硬件都低于一秒。旧失败样本保留。

新增检查覆盖目录合并、日志先后顺序、暂存中断、文件发布后中断、磁盘 I/O 失败恢复；既有回归继续检查并发、隔离、关闭选项、事实证据、召回和任务记忆。各平台和实际安装包验收详见发行附件 ACCEPTANCE-RESULTS.json，未运行项不计为通过。

运行 `koder update` 后用 `koder --version` 确认版本。Windows 完整包、macOS 和 Ubuntu 平台包均保留。仓库及 Stars 保留，授权边界不变，官网不更新。参见[安装指南](INSTALLATION.md)、[Ubuntu 中文教程](UBUNTU.zh.md)和[学习说明](MARKDOWN-LEARNING.zh.md)。
