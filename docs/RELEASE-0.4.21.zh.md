# Koder CLI 0.4.21 更新说明

修复指定 GitHub 仓库寻找 Skill 时“已经找到却显示为空”的问题。`repo:anthropics/skills` 这类限定条件现在用于筛选仓库，新的查找和缓存结果一致，限定查找也不会退回搜索无关仓库。

会话快捷键、子 Agent 模型匹配和工具参数共用同一份四档思考强度：深度、标准、快速、关闭。模型与强度仍分别选择，保留服务商不支持时的明确降级说明。

## 安装后操作

Windows 下载 PowerShell 或 CMD 安装器；macOS 下载 shell 安装器。已有安装可运行 `koder update`，然后用 `koder --version` 确认 `0.4.21`。各安装器使用同一份运行包，原有 Windows-MCP、SolidCraft 平台内容继续保留。

按照[中文手把手操作课](SELF-FETCH-AND-SUBAGENTS.zh.md)完成“找 Skill → 固定版本安装 → 读内容 → 完成原任务”，以及“两份输入 → 两个子 Agent → 核对文件与回执”练习。附件示例 ZIP 提供输入文件和练习说明。[完整配置](TASK-ORCHESTRATION.zh.md)仍适用。

工具与模型轮次默认不设产品总次数上限；用户设置的费用预算、取消、显式次数限制和安全保护继续生效。180 是同一根任务尚未收集释放的子 Agent 数量上限，不代表同时执行 180 次付费请求。MCP、桌面、邮件和真实外部账号操作仍由父任务承担。
