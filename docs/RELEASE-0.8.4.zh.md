# Koder CLI 0.8.4

[English](RELEASE-0.8.4.md) · [简体中文](RELEASE-0.8.4.zh.md)

本版合并 Windows 受保护凭据修复、网页返回 CLI 与原生记忆改进。安装和更新统一使用 [CLI 官网](https://kodermodule.com/cli-download.html)。本文介绍版本内容，是否正式上线及各平台验收结果以发布回执为准。

运行 `koder login`，选择打开官方账号网页或显示二维码。网页已有登录状态时，可直接确认本次 CLI 授权。原终端持续轮询本次事务，核验账号并保存受保护凭据；支持的环境可点击“返回 Koder CLI”切回原窗口。返回按钮只负责切换窗口，登录不依赖点击。无法自动切回时手动返回即可，不要在原窗口仍等待时另开登录。

Windows 使用当前用户 DPAPI，并在网页登录前检查加密、存储和读回；macOS 使用钥匙串，Linux 桌面使用 Secret Service。`koder account doctor --json` 给出平台、失败阶段及原因，不输出令牌。`koder account status` 区分可自动续期的已登录会话与未登录状态。本机密钥模式独立保留，不冒充云端账号，不新增电脑权限。

原生记忆从现有本地记录中检索与任务相关、带来源的事实，遵守账号和项目隔离。相同内容去重，冲突明确保留，并支持更正、遗忘；遗忘后迟到结果不能把旧事实写回来。上下文压缩保留当前任务的写入约束和证据标识。原有学习关闭选项继续生效，不增加第二套数据库、重复 Skill 或额外常驻服务。

参阅[完整登录教程](ACCOUNT-LOGIN.zh.md)、[本机模式与返回终端](LOCAL-ACCESS-AND-RETURN.zh.md)、[原生记忆设计](DEERFLOW-MEMORY.zh.md)。合成账号服务测试、实际包回归、真实注册登录、浏览器返回和各系统实机分别记录，不把其中一项通过扩称全部通过，也不宣称本版提升了模型质量评分。

## 发行核对与未验范围

冻结账号测试共 **200 项：198 项通过，2 项本机密钥条件用例跳过**；实际包记忆内核测试另记 **23 项通过、0 跳过**。不能把两组相加写成所有账号或本机密钥路径均已执行。另有 macOS 命令检查和一次隔离安装，复用已有兼容 Node 与自有本机回环镜像；这不是新的公网下载或 Windows/Ubuntu 原生安装验收。

真实用户注册、真人账号批准和实际桌面回跳仍为 **NOT_RUN**。适配夹具、合成 HTTP 账号和组件编译不能证明原生浏览器点击；账号网页返回按钮的部署需单独确认。记忆夹具也不代表模型分数提升或所有召回质量都通过。

**已于 2026 年 11 月 3 日发布。** 正式提升记录确认新的生产版本；正常 DNS、默认 CA 的 HTTPS 记录核对了精确 0.8.4 稳定清单、10 个中英文入口页及 7 个原版本清单/安装器/校验文件，共 18 项定向检查。

产品方另完成 **32 个原件、共 1,111,714,572 字节**的公网完整大小与 SHA-256 核对。Linux 包从第 1,048,576 字节续传，返回 HTTP 206 与匹配的 Content-Range，最终文件哈希一致。这是产品侧 32 文件结果，不代替官网负责人更大范围的 **PUBLIC413**；后者仍待独立最终回执。

新旧默认官方更新检查均 exit 0，未使用镜像覆盖，也未执行安装：旧 0.8.1 发现 0.8.4，0.8.4 显示已是最新版。[精确 0.8.4 的 Windows Server 2022 VM 任务](https://github.com/KarmenLoop/koder-cli/actions/runs/41535590608)核对官网下载包/安装器哈希后，七项受保护存储及合成账号检查也已通过。

生产真人注册/登录、浏览器返回终端及 Windows 10/11、Ubuntu 原生 GUI 仍为 **NOT_RUN**。账号网页返回按钮的部署和真人点击验收与 CLI 发布分别记录；本结果不代表所有平台通过或模型质量提分。包内保留 79 个唯一 Skill 与原有第三方声明；原生记忆改变了私有内核，不写成与上一内核逐字节不变。

隔离环境中的 8 项记忆教程操作属于补充本地证据，不累加为账号测试总数或模型分数。首次测试目录配置导致的 EULA 拒绝仍单独保留，没有改写为一次成功执行。
