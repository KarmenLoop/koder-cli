# Koder CLI 0.5.6

本版重点修复任务没有结果、失败后反复空转，以及网站已写文件却没有交付可用地址的问题。

- 最终答复为空时，最多补答两次；补答不开放工具、不重放已执行操作，沿用原模型和费用预算。仍无结果则明确报错。
- 相同失败反复出现时停止空转，给出原因。默认工具次数继续不设总上限，取消和费用预算保留。
- 教程中拒绝修改后，先询问是否重新提出，再进入新的审批；不自动重复请求已拒绝的操作。
- 网站默认接入 Fullstack Web Delivery 的需求、完整规划、适用规格、布局选择、开发、验证与交接流程。原 Skill v0.9.1 的 29 个资源不改写，保留许可与来源。
- 网站交付核对当前源码、适用规划/设计记录、实际本地预览状态与最终地址。自动预览就绪后再进行交付检查；不把文件索引页当成网站。
- “继续”可承接最近未完成的网站任务，先核对已保存文件哈希，再补剩余工作。用户明确不打开浏览器或不需要预览时保留该范围。
- 小上下文优先保留当前任务、记忆约束及未核实操作证据；按需显示工具，保留相关的代码图谱、PDF、资料库和已连接应用发现入口。
- 修复学习回顾与召回不一致、写入后上下文包过期，以及安装器目标版本和打包版本不一致的问题。

## 使用方式

在新项目或现有网站目录中直接提出目标。新网站继续使用独立 Project 和项目锚点；旧网站修复保持既有范围。静态网站不强制添加账号、数据库或后台。Setup 中关闭网站 Skill 的选择仍有效。

[网站流程](website-delivery.md)说明需求、规划、设计与交付检查；[任务结果与恢复](task-results.md)说明未完成、失败和结果不明的处理。完整命令继续见[中文使用教程](USER-GUIDE.zh.md)。

## 安装与验证范围

Windows PowerShell/CMD 与 macOS/Linux 安装器使用同一份 0.5.6 运行包和 SHA-256 清单。按[安装说明](INSTALLATION.md)更新；保留配置、历史和关闭选择。

发布附件 ACCEPTANCE-RESULTS.json 分层记录源码回归、解压包执行、隔离 macOS 安装升级、原失败和未验项。脚本模型驱动真实本地工具的测试不等于真实付费模型质量评测；HTTP 预览成功也不等于视觉、无障碍或业务验收通过。

Windows 实机冷启动/更新、Console/ConPTY/IME 和 Windows-MCP 图形操作由 beta 专员继续验证。本轮真实账号写入、付费模型质量与三端通知可见性仍为 NOT_RUN；macOS 锁屏原生组件仍是未签名 HOLD 候选。本轮仅更新 GitHub，不部署官网。
