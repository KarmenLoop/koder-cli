# Koder CLI 0.4.12

## 本版更新

- 新增 `koder migrate` 设备迁移向导，Setup 与 `/migrate` 同步接入。将项目和能够确认归属的本地会话导出为口令加密包，在新设备导入独立配置，或通过已配置的 SSH 连接发送。源设备数据保留，新设备的凭据和电脑权限需要重新设置。
- 内置 180 课中文完整课堂：12 个单元，含手把手与开发者路线、示例、作业、自测和本地笔记。保留原 30 课英文教材；新增 31–180 课为中文。
- 修复授权码或迁移口令快速粘贴时可能回显的竞态：先关闭终端回显，再显示保密输入提示。

同时带入此前候选中的 GitHub 仓库/用户名大小写对账修复，以及小上下文窗口下的技能目录精简。原 GitHub 绑定、邮箱、MCP、Skills、模型路由、多窗口、实时输入、取消及权限边界继续保留。迁移不会搬走正在运行的进程、重放待执行操作或授予目标设备权限。

## 安装与升级

Windows CMD、PowerShell 与 macOS 平台安装器使用同一版本化 CLI 运行包。打开[官网安装入口](https://karmenloop.com/download.html#cli)，或运行 `koder update`，然后确认 `koder --version` 显示 **0.4.12**。本次更新 CLI；桌面应用版本独立。

## 验证范围与限制

迁移候选通过 56 项独立的无密钥定向检查，包含真实 macOS PTY 导出和接收端子进程。课堂候选通过 20 项课程/配置检查、8 项 DOM 模拟检查及 6 项教学实验检查。发行包与线上读回单独记录；这些结果不等于整产品全量或实机认证。

Windows 10/11、PowerShell 5.1 冷启动、ConPTY/IME、Windows-MCP 图形操作、真实 Windows↔macOS 迁移、远程 SSH 与目标账号重连仍待实机验证。SSH 测试使用受控传输适配器。DOM 测试不能替代真实浏览器视觉和无障碍验收。原工作流失败及平台 HOLD 记录保留。未签名 macOS 锁屏原型不包含在本包。

迁移上限：20,000 文件、单文件 64 MiB、内容 128 MiB、加密包 200 MiB。依赖、Git 历史、受保护凭据、浏览器登录态、待执行任务及原生密钥加密的个性化库不自动搬运。查看迁移报告，目标验证完成前保留源设备；导入的自定义 Skills 默认关闭，待复核。
