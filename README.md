# Koder CLI 0.4.0-preview.4

安装后的教程、首次设置和授权说明已更新。提供23课中文/英文教程，覆盖PowerShell、CMD、macOS和Linux；旧版已毕业用户从新增第17课续学，原先未完成进度保留。

- 新增使用许可、电脑与文件权限、记忆目录、群私聊/跨设备、习惯学习、当天状态、灵魂、每日反思、主动服务、Gamma/MCP以及API/上下文排障。
- 接受软件许可前可以查看只读帮助和 `koder learn --print`；实际功能仍按许可与各项授权运行。
- 四项可选功能分别说明用途、共享范围、费用和关闭方式；ENABLE/DISABLE/SAVE分别对应开启、关闭和手动编辑。
- 新增 `koder permissions revoke` 撤销后续电脑工具授权，设置页提供主目录、完整工作模式和撤销入口。
- 安装器、README和包内ACCEPTANCE.md使用一致的授权说明；已接受协议后显示当前状态。
- 现有Koder-EULA-1.0全文未改变，不要求为同一许可重复接受。第三方和旧GPL权利保留。

完整串行回归：357项，354通过、0失败、3项Core环境跳过；最终协议状态显示修正另有6项定向检查通过。安装包在隔离macOS环境验证旧版升级、配置与记忆保留、八套教程文本、模型本地HTTP请求、帮助/协议门和卸载。Windows原生、真实渠道/Gamma、多设备和生产Core仍未验收。

从preview.3运行 `koder update --check`、`koder update`、`koder version`。0.3.0/0.3.1/preview.1/2先执行README中的官方安装命令一次，获得新的GitHub更新器，无需清空配置。
