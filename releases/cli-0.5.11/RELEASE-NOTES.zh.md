# Koder CLI 0.5.11

修复 Windows 首次通知死循环：应用从未发过通知时，系统可能尚无权限状态条目。现在区分首次使用、明确拒权和未知错误，仅在实际发送时注册当前用户下的 Koder 显示名称，保留用户关闭开关和系统策略。状态检查不写设置；提交成功仍不等于用户已看见。

短回复结束后不再启动不必要的系统进程检测终端焦点；安静时段积压通知只核对桌面是否可用；无终端的 Windows 任务不再把隐藏子进程的控制台当成用户正在看的终端。长任务仍按需要判断焦点，取消、权限、日预算和持久回执保持有效。

Windows 虚拟机工作流覆盖 PowerShell 5.1 / CMD 安装、多窗口隔离、超过 16 步的长任务、邮件本地协议夹具，以及通过 Koder 真实传输层调用内置 Windows MCP。三窗口原有 30 秒门槛保留，发行验收附件分别记录成功、历史失败和未运行项。

运行 `koder update` 升级，或使用[安装说明](DOWNLOADS.zh.md)。Ubuntu 24.04 继续提供[独立安装入口](UBUNTU.zh.md)。原有平台功能、Skills 和当前完整课堂均保留。

Windows Server 虚拟机结果不等同于 Windows 10/11 实机。测试邮箱与本地 TLS 不等于真实 163/Gmail 投递成功；系统接受通知提交也不保证用户已经看见。macOS 锁屏组件继续保留未签名候选状态。本次不更新官网。
