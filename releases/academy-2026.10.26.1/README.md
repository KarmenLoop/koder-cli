# Koder Academy — hands-on edition 2026.10.26.1

The Chinese classroom contains 1,800 lessons in 120 units. This revision turns each lesson into a saved practice workflow: original input, a blank workbook, a baseline result, a changed condition, troubleshooting and a handoff record.

- 1,800 individual workbooks, with beginner instructions and developer extensions.
- Twelve domain guides for terminal use, configuration, files, task control, programming, websites, backend systems, testing, research and writing, office work, Skills/MCP, and GitHub delivery.
- A complete first exercise with observed outputs of 750 and 900.
- An optional local helper that creates a new practice folder and identifies missing workbook sections. It does not execute examples, call a model, or grade correctness.
- Existing lesson identifiers, original material, browser progress, and the 30 English lessons are retained.

Open the [hands-on guide](https://karmenloop.com/academy/docs/courses/PRACTICE-GUIDE.zh.html), the [full classroom](https://karmenloop.com/academy/docs/courses/index.zh.html), or download the ZIP below.

Validation: 24 local regression tests passed, including 72 supplied program baselines. The packaged helper and lesson 721 were also exercised after extraction. The browser was checked for navigation, practice instructions and a real workbook download. Student exercises and real account/device actions require separate evaluation; a filled workbook is not a passed exercise.

This is a classroom release, separate from CLI 0.4.16. It does not replace the Windows or macOS installers, change the CLI update channel, or install software.
