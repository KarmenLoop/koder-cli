# Koder CLI 0.4.0 publication

Koder CLI 0.4.0 is the GitHub Latest formal release. Windows CMD and PowerShell installers and the macOS/Linux shell installer are available from the [website](https://karmenloop.com/download.html) and [GitHub release](https://github.com/KarmenLoop/koder-cli/releases/tag/cli-0.4.0). These are CLI installers, not signed desktop EXE or DMG applications.

All 20 assets were downloaded anonymously from GitHub and the website and matched the final local SHA-256 values. Both update feeds report 0.4.0. Ten current product/guide pages and 36 installer/tutorial links were read back. The deployed file inventory retains every previous path and both regular functions and all four edge handlers.

A task-local installation of preview.30 ran its actual `koder update` command against the public website, exited successfully and launched 0.4.0. Its test settings were preserved. Fresh installation and installer-based upgrade checks also passed on Windows Server x64, Intel Mac and Apple-silicon Mac. Read [acceptance](ACCEPTANCE.json) for the test scope and remaining native/account limits.

The original Netlify CLI HTTP 422 and preview-login HTTP 401 records remain in the internal evidence. The existing ready draft was reconciled and promoted without a duplicate deploy. A strict Chinese-home title mismatch was traced to the existing language redirect and the current English home was verified. These diagnostics were not removed or relabeled as initial passes.

[Public verification receipt](PUBLIC-VERIFICATION.json) records the final file identity and public update check. Previous preview.30 assets remain available for rollback.
